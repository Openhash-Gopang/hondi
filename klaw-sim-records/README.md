# 가상 판결문 생성 테스트 기록

hondi.net "시뮬레이션 결과" 버튼(`/pages/klaw-simulation-record.html`)이 가리키는 증거 자료 폴더입니다.

| 폴더 | 내용 |
|---|---|
| data/ | 사건별 점수표(case_scores.csv), 회차별 집계, 요약 JSON, 4월 요약 처리 목록 |
| reports/ | 실증결과 보고서(v1.6, v2.0), 배치 보고서, 방법론 갱신 제안서, 요약·책자 |
| methodology/ | 출력 형식 v13.2, 방법론 v15.1(영문), 패치 v15.2, 평가 기준 |
| papers/ | 논문 초안 1~4 |
| code/ | 생성·검증·평가 스크립트(API 키 삭제본), 스키마, 웹앱·대시보드 소스(참고용) |
| raw/ | 사건별 평가 원문(zip), 평가 완료 가상 판결문(zip), 추론 기록(zip), 실행 로그 |

## 집계 기준
- 점수 파일: `scores/N회차` (7점 이상 합격) + `scores/N회차 재평가 대상` (7점 미만)
- 평가 기준 v1.6, 10점 만점, 평가 기간 2026-05-12 ~ 05-15
- 고유 사건 348건 / 점수 부여 337건. 최초 평균 7.44, 최종(재평가 반영) 평균 7.97
- 1·2심 점수는 AI 추정 참고값이며 실제 1·2심 판결문과의 대조가 아님
