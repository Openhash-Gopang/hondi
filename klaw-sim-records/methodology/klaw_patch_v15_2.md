## 1. A-0-S [7단계] [8단계] 신설 — 형사 구성요건 실질적 해석 의무화

**발동 대상:** 형사 구성요건 요소('효용', '타인의 물건', '공무상표시' 등) 해석 시  
**근거 사례:** #0003 (2024도6213, 1.5점) — '효용 해함' 협소 해석으로 결론 역전

현행 공리 S [1단계]~[6단계]에 다음 두 단계를 추가한다.

```
[A-0-S 7단계] 규범적 평가 요소 검토
  해당 구성요건이 보호하는 보호법익의 관점에서,
  핵심 단어의 의미를 확장 해석할 수 있는 규범적 근거가 존재하는지 검토한다.
  출력 형식: "[규범적 평가] 보호법익: ___ / 확장 해석 가능성: 있음·없음·조건부"

[A-0-S 8단계] 실질적 판단 사례 경향 분석
  유사 구성요건 사안에서 대법원이 문언의 사전적 의미를 넘어
  실질적·규범적으로 평가한 판례 경향(있는 경우)을 분석한다.
  판례 번호 없이 원칙 수준 서술 의무 (공리 J 준수).
  출력 형식: "[실질적 경향] 대법원은 ___ 쟁점에서 ___ 방향으로 판시하는 경향이 있음"
```

**미이행 시:** 형사 구성요건 해석 사건에서 A-0-S 불완전으로 세부 논증 -0.5점  
(강제규칙 10 위반 효과와 합산 적용)

## 2. STEP-3 조세·행정 준용 추적 서브모듈 신설

**발동 대상:** 조세특례·행정처분 사건에서 적용 조문에 준용·인용 규정이 포함된 경우  
**근거 사례:** #0015 (2021두51041, 3.9점) — 구 조세특례제한법 제121조의4 준용 규정 간과

```
[STEP-3-T: 준용 추적 서브모듈]
다음 감지 문구 발견 즉시 자동 발동:
  ① "준용한다", "적용한다", "의한다", "에 따라", "에 의하여"

발동 시 수행 절차:
  (a) 피준용 조문(모법·시행령·시행규칙·부칙) 전체를 분석 범위에 편입
  (b) 피준용 조문의 요건·효과·예외 조건을 B-5-C 모듈로 매핑
  (c) [법령 체계도] 출력: "모법 제N조 → (준용) → 시행령 제M조 → 적용 요건: ___"

미발동 시 (준용 문구 존재함에도 서브모듈 생략): 핵심 법리 -1.0점
```

## 3. B-5-A §역전 심층 질문 추가 — 원심 역전 시 다중 법리·대체 구제수단 확인

**발동 대상:** B-5-A 원심 역전 신호 감지 시 (기존 조건 유지, 질문 항목 추가)  
**근거 사례:** #0016 — 손해 확정 여부 판단 시 공탁청구권 등 구제수단 미검토

기존 B-5-A 발동 후 다음 질문을 의무적으로 추가 수행한다.

```
[B-5-A §역전 심층 질문]
① 원심이 취한 법리와 K-Law가 취한 법리의 구체적 차이점은 무엇인가?
② 대법원이 원심을 파기하는 근거가 '법리오해'인 경우,
   해당 법리가 단일한지 다중적인지 검토하라.
   → 다중 법리인 경우: 각 법리별 독립적 판단 수행 후 결론 합산
③ 원고(또는 피해 당사자)에게 본 판결 외에 별도 구제수단이 존재하는가?
   (예: 공탁청구권, 승계집행문, 배분이의 소송 등)
   → 존재하는 경우: 해당 구제수단의 실효성이 손해의 현실적 발생에 영향을 미치는지 판단
```

**미이행 시:** B-5-A 발동 후 심층 질문 생략 시 세부 논증 -0.5점

## 4. C-α (11)(12) 신설 — 논증-결론 정합성·주문-이유 일치 검증

**근거 사례:** #0009 (2022다255454, 5.0점) — 가정적 시나리오 도입으로 논증과 결론 모순

C-α 체크리스트에 다음 두 항목을 추가한다 (기존 10개 항목에 이어 11번, 12번으로 편입).

```
C-α (11) 논증-결론 정합성
  □ 논증 과정에서 상정한 가정적 시나리오('~으로 볼 경우', '~라면' 등)가
    최종 결론과 모순되지 않는지 점검한다.
  □ 가정적 시나리오의 결론이 주된 논증의 결론과 충돌할 경우,
    해당 가정적 경로를 삭제하거나 [별개 시나리오]로 분리 출력한다.

C-α (12) 주문-이유 일치
  □ 판결 주문(상고기각/파기환송/파기자판 등)과
    판결 이유의 방향성(원고 승·피고 승·일부 인용 등)이 일치하는지 확인한다.
  □ 불일치 감지 시: 이유 재검토 후 주문 또는 이유 중 하나를 정정하고
    [주문-이유 불일치 수정] 기록을 남긴다.
```

**C-α 완료율 기준 갱신:** 기존 11개 → 12개 항목으로 변경.  
완료율 50% 미만 기준은 6개 미만 완료로 자동 조정.

## 5. 앙상블 v14.3 → v14.4 — 경고 대응 체계 강화

**근거 사례:** #0011 (공리 J 위반, 허위 판례번호 생성), #0003·#0009 (공리 G 위반, 저확신도 판단유보 미선언)

```
[앙상블 v14.4 변경 사항]

(a) [앙상블-경고] 발동 시 처리 절차 강화
    현행: 재실행 권고
    변경: A-0-S 단계 및 C-α 단계 재실행 의무화
          재실행 미이행 시 [앙상블-경고 미처리] 기록 + 확신도 -1 조정

(b) [앙상블-주의] + 확신도 < 0.5 동시 발생 시
    현행: [조건부 결론] 권고 경고 출력 (B-7-④ 준용)
    변경: [판단 유보] 자동 삽입 의무화 (공리 G 강제 연계)
          주문: "확신도 부족으로 판단 유보 — 추가 정보 필요"
          자동 삽입 미이행 시: 결론 방향 -1.0점

(c) B-5-B 판례 참조 시 무결과 처리 로직 (공리 J 방지)
    판례 데이터베이스 검색 결과 없음 또는 확인 불가 시:
    허위 판례번호 생성 대신 → "참조 판례 없음. 원칙 수준 서술로 대체."
    강제 출력 형식: "[판례 미확인] 관련 판례 특정 불가 — 아래 법리는 원칙 수준 서술임"
    위반(허위 번호 생성) 시: 공리 J §7 감점 기준 그대로 적용
                             (-1.0점, 2건 이상 최대 -3.0점)
```
