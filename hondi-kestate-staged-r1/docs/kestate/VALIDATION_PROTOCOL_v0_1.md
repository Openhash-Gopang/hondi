# K-Estate 가치평가 검증 규약 v0.1 (초안)

> 형식 참조: K-Law의 방법론 개정·검증 관행(`klaw` 저장소 `klaw_v16_1.md` 패치 노트, `library/benchmark/method/` 사전등록 설계 문서).
> 이 문서의 기준값은 **아직 정해지지 않았다** — 사람이 사전등록한 뒤에만 유효하다. 수치를 지어 넣지 않는다.

## 1. 원칙 (K-Law에서 가져온 것)

1. **개발 세트와 표본 밖(holdout) 세트를 분리한다.** SP(SP-24a)나 코드 상수(σ 가산 사전값, 정비 단계표 등)를 고칠 때는 개발 세트만 본다.
2. **고친 뒤에는 한 번도 보지 않은 표본으로만 검증한다.** 진단에 쓴 사건은 검증에 다시 쓰지 않는다(표본 오염 방지).
   코드: `assertNoContamination(devIds, holdoutIds)`.
3. **시간 순으로 나눈다.** 미래 정보가 과거 추정에 새지 않도록 `splitByTime(records, cutoff)`로 자른다.
4. **모든 개정에 진단 → 처방 → 검증 기준을 patch note로 남긴다.** 검증 기준은 검증 전에 적는다(사전등록).
5. **한 번에 한 가지 원인만 고친다.** 여러 변경을 한 번에 넣으면 어느 변경이 효과를 냈는지 구분할 수 없다(K-Law v16.1이 같은 이유로 편입 순서를 기록으로 분리했다).

## 2. 기록 단위

추정마다 다음을 저장한다: `case_id`, `as_of`(추정 기준일), `track`, 산출 시점의 SP·코드 버전, 단계별 증거 튜플(출처·조회일·기준일),
`fair_value`, `sigma`, `collateral_value`, `flags`, 그리고 **사후에** 채워지는 `realized_price`·`realized_net`(실제 매각가·순회수).
- 실현값은 매각된 사건에만 존재한다. 취하·미매각은 정답이 없으므로 **제외하되 건수를 항상 함께 보고**한다(`n_unrealized`, `n_unsold`).
  이 표본 선택은 결과가 좋아 보이는 쪽의 편향을 만들 수 있다.

## 3. 트랙별 채점과 채택 기준 (기준값은 사전등록 시 기입)

| 트랙 | 지표 | 함수 | 채택 기준(사전등록) |
|---|---|---|---|
| 중재 | 중앙값 편향, MdAPE, PE20 | `evaluateMediationTrack` | 표본 밖에서 편향 허용치 이내, MdAPE·PE20이 개발 세트 대비 악화되지 않을 것: **(값 미정)** |
| 대출 | 커버리지(Wilson 95%), 평균·최대 부족 폭, 보수성 비용, 핀볼 손실 | `evaluateLendingTrack` | 커버리지가 목표와 통계적으로 양립하고 미달이 유의하지 않을 것: **(값 미정)** |

- 두 트랙은 **따로 채점**한다. 위험을 과소평가하면 중재 점수는 멀쩡한데 대출 커버리지만 무너질 수 있다(`sim-tracks.mjs`).
- 소표본(30건 미만)은 `low_sample`로 표시하고 결론을 내리지 않는다.
- 단순 기준선(예: 감정가 × 지역 낙찰가율 중앙값)을 이기지 못하면 정교함은 비용일 뿐이다(`compareToBaseline`).

## 4. 3단계 구조의 검증 질문 (단계별 절제 실험)

각 단계가 실제로 기여하는지 확인하려면, 표본 밖 사건에 대해 단계를 하나씩 끄고(예: 시점수정 계수 1.0 고정) 지표가 나빠지는지 본다.
- 국가 단계 제거 시 중앙 편향이 커지는가(시점수정이 실제로 편향을 줄이는가)?
- 지역·개별 단계의 σ 가산 제거 시 대출 커버리지가 무너지는가(가산 사전값이 필요한 크기인가)?
- 정성 위험이 σ만 키우고 중앙 추정을 움직이지 않는다는 설계(R8)가 옳은가 — 정비 단계별 실제 가격 차이가 관측되면 중앙 계수 도입을 별도 개정으로 검토한다.
- 증거를 못 구한 사건(`unavailable`·`unverified`)의 오차가 구한 사건보다 실제로 큰가(불확실성 가산이 옳은 방향인가)?

## 5. patch note 템플릿

```
## ══ vX.Y 패치 노트 (YYYY. M. D. — 지시자/사유) ══
## 진단: (표본 밖 검증에서 무엇이 어떻게 틀렸는가 — 지표·건수 포함)
## 처방: (무엇을 한 가지만 바꾸는가 — 어느 규칙·상수)
## 검증 기준: (다음 표본 밖 라운드에서 무엇이 얼마나 개선되면 채택하는가 — 검증 전에 기록)
## 사용한 사건: (개발 세트 id 목록 — 이후 검증에 재사용 금지)
```

## 6. 아직 정해지지 않은 것

- 채택 기준값(위 표), 표본 밖 라운드의 크기, cutoff 날짜.
- 실현값의 출처(합의매각 결과, 법원 경매 공개 결과 등)와 수집 권한.
- 지수·인구·정비구역 자료의 지역별 가용성 조사(자료가 없는 지역의 비중).
