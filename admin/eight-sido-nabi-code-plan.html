2 배경과 목적

방문자는 게시판·전화·방문으로 흩어진 안내를 직접 찾아야 하고, 외국인 관광객은 언어 장벽까지 더해집니다. 이 제안의 목적은 코드를 인식하는 한 번의 동작으로 해당 기관·부서의 AI 비서와 사람처럼 대화하게 하는 것이며, 시범으로 다음을 검증합니다.

  • 코드 인식률
  • 기관 AI의 응대 품질
  • 시민·관광객 이용량
  • 기관 담당자의 부담 감소

서울·경기(수도권 대도시), 충남·충북·전북·전남(중소도시와 농촌), 강원·경북(넓은 산간·관광 지역)은 행정 환경이 서로 달라, 같은 코드가 여러 환경에서 통하는지 보기에 알맞습니다. 이 사업은 나비 시스템의 상용화 전 최종 필드 테스트 기간(2026-09-01~12-31) 다음 단계인 확대 시범입니다. 제주도청(2026-10-22 초안)과 부산·울산·경남(2026-10-27 초안)에 같은 취지의 시범을 제안했으며, 이 제안은 그 설계를 8개 시·도로 옮긴 것입니다.

3 나비 숫자 코드

나비 숫자 코드는 노란 나비 로고와 1~10자리 숫자 칸으로 이루어진 시각 코드입니다. 숫자는 7세그먼트 방식으로 칸마다 그려지고, 쓰지 않는 칸은 회색 빈칸으로 남습니다. 사람이 숫자를 읽을 수 있으면서 카메라로도 인식되도록 설계되었습니다.

숫자 코드에는 기관이 고른 번호 대신 전화번호를 입힐 수도 있습니다.

예시 코드 (관공서·관광지·시장·식당)

※ 상호에 ○○가 들어간 사업장은 예시 상호이며, 모든 번호는 설명용 가상 번호입니다.

작동 방식

  1. 기관·사업장이 신청해 숫자 번호를 받습니다(전화번호를 쓸 수도 있음).
  2. 안내판·간판·창구에 코드를 붙입니다.
  3. 방문자가 카메라로 코드를 비춥니다.
  4. 시스템이 번호로 해당 기관의 AI 비서를 찾아 연결합니다.
  5. 방문자는 문서·전화 대신 대화로 안내를 받습니다.

소유권 보호

번호의 소유권은 기관이 서명으로 주장(claim)한 내역에 따르며, 다른 주체가 같은 번호를 가로챌 수 없도록 합니다.
