아래 명령으로 사본을 이 위치로 모으고 권한을 본인 계정으로 제한했습니다(ssh-key-2026-05-08.key만 이동 성공). 삭제 명령은 이동이 모두 성공한 뒤에 실행해야 합니다.

$d = "$HOME\.ssh\oracle"
New-Item -ItemType Directory -Force $d | Out-Null
# 원본을 찾아 이동 (경로가 다르면 수정)
Move-Item -Force "$HOME\Downloads\gopang-l1.key" "$d\gopang-l1.key"
Move-Item -Force "$HOME\Downloads\ssh-key-2026-05-08 (1).key" "$d\ssh-key-2026-05-08.key"
# 본인만 읽을 수 있게 제한
icacls $d /inheritance:r /grant:r "$($env:USERNAME):(OI)(CI)F"
icacls "$d\*" /inheritance:r /grant:r "$($env:USERNAME):F"
# 임시 사본 삭제
Remove-Item C:\sshtmp -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item "$HOME\.ssh\oci_key" -Force -ErrorAction SilentlyContinue

접속 명령은 다음과 같습니다.

개인키 내용이 대화에 노출된 적이 있습니다. 조정 작업을 재개할 때 오라클 콘솔에서 새 키 쌍을 만들어 서버의 authorized_keys를 교체하고, 이전 키는 지우는 것을 권합니다. 교체 후에는 이 절의 파일명만 갱신합니다.

5. 계정 접근 상태

  • 오라클 로그인 정보: 테넌시 tensorcity, Default 신원 도메인, 사용자 tensor.city@gmail.com.
  • 모바일 인증 앱을 재설치하면서 오라클 항목이 사라졌고, 우회 코드와 모바일 통지도 쓸 수 없어 MFA 초기화를 오라클 지원에 요청해야 합니다(Contact Us 또는 청구서 메일의 연락처). 요청은 직접 보내야 하며 아직 보냈다는 확인이 없습니다.
  • Cloudflare는 정상 로그인 상태입니다. 보안 키 "oracle"과 이메일 2단계 인증이 있고, 앱 인증(TOTP)은 사라진 항목이 남아 있으니 백업 코드를 발급해 두는 것을 권합니다.

6. 재개할 때 순서

  1. 오라클에 MFA 초기화 요청 → 콘솔 로그인.
  2. 인스턴스 목록에서 144.24.90.233이 무엇인지 확인하고, 비용 분석(Cost Analysis)에서 서비스별 요금을 확인.
  3. 선택지 결정(3절). A1 이전이면 이전 계획서를 따로 작성한 뒤 진행: A1 인스턴스 생성 → 데이터 복사(PocketBase 31개) → 읽기 전용 검증 → DNS 전환 → 기존 서버 중지 → 일정 기간 뒤 삭제.
  4. DNS가 l1-hanlim(무료 마이크로)을 아직 가리키는지 확인하고, 남은 서버라면 정리를 검토.
  5. SSH 키 교체(4절). gopang-l1.key를 찾지 못했다면 콘솔에서 새 키 쌍을 만들고, 인스턴스의 콘솔 연결 또는 기존에 접속 가능한 키로 authorized_keys에 새 공개키를 추가합니다.
