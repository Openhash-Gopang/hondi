전자동 AI 정부 테스트 (2026.9.1~12.31)

대한민국 최초의 전자동 AI 정부 테스트를 진행합니다. 입법·사법·행정 세 영역에서 동시에 진행되는 이번 현장 테스트의 범위와 절차를 안내합니다.

1dpaper API 신청 현황과 '관제탑 원칙'

대한민국 정부는 2026년 6월부터 AI 정부 전환을 본격화하고 있습니다. 혼디는 이 전환에서 아직 채워지지 않은 마지막 2%인 사용자 인터페이스를 메우려는 민간 프로젝트(AI City Inc.)입니다.

혼디 개발자 그룹은 행정안전부 dpaper API를 비롯해 국세청 API, 지식재산처(구 특허청) API 등 관련 정부 API를 이미 신청해 둔 상태입니다. 행안부의 정식 승인이 나기 전까지는, 이들 API를 통한 실제 연동 기능은 제한적으로만 동작합니다.

승인 이전 구간에서도 사용자가 절차를 오해하거나 잘못된 기대를 갖지 않도록, 혼디는 모든 단계에서 '관제탑 원칙'을 지킵니다.

관제탑 원칙이란?
공항 관제탑은 여러 비행기의 모든 정보를 한꺼번에 조종사에게 쏟아붓지 않습니다. 지금 이 비행기에 필요한 다음 한 걸음만, 정확한 순서로 안내합니다. 혼디도 마찬가지입니다. 관련 규정과 절차를 통째로 나열하는 대신, 사용자의 현재 상황을 먼저 확인하고, 지금 단계에서 필요한 안내와 다음 행동만을 명확히 제시합니다.

2입법·사법·행정, 세 영역의 테스트

혼디의 전자동 AI 정부 테스트는 국가 권력의 세 축을 따라 나누어 진행합니다.

사법 — 변호사 중개 민사조정 시스템

민사 소송을 대상으로, 혼디(K-Law)의 가상 판결 시뮬레이션을 시범 운영합니다. 사건의 개요를 정확히 입력하면, 수년 뒤에나 나올 대법원 판결문을 상당한 신뢰도(자체 테스트 결과 약 90%)로 미리 작성해 보여줌으로써, 승산이 낮은 소송의 불필요한 남발을 억제하는 효과를 기대합니다. 다만 이 시뮬레이션은 인간 변호사가 직접 중재하거나 분쟁 당사자 쌍방이 동의한 경우에 한해서만 법적 효력을 가지며, 혼디의 AI 기능은 인간 변호사를 대신하지 않습니다.

입법 — 시민 청원 자동 연계

청원이 일정 수 이상의 동의를 얻으면, 입법부가 정한 정식 시민 청원 절차로 자동 연계됩니다.

행정 — 중앙부처·지방관청·공기업의 AI 버전

중앙 정부 부처 전체(지식재산처, 국세청, 경찰청 등)와 지방 관청 전체(도청·시청·읍면동), 공기업까지 포함하는 전면적인 행정 AI화입니다. 제주도를 예로 들면 다음과 같은 체계로 구성됩니다.

  • 제주도청 및 산하 부서 전체
  • 제주시청·서귀포시청 및 산하 부서 전체
  • 제주도 43개 읍면동 행정복지센터 및 부서 전체

(부서·센터별 상세 명단은 조직 개편에 따라 수시로 변동되므로, 테스트 기간 중 hondi.net에서 실시간으로 확인하실 수 있습니다.)

사람이 중심 — 혼디는 보조입니다

혼디는 서류 준비, 정보 수집, 절차 안내, 초안 작성까지 수행하지만, 법적 자문·판결·인허가 등 최종 판단과 책임은 언제나 해당 분야의 사람에게 있습니다.

3혼디 처리 예시 — 정부24 주요 민원

정부24를 통해 접수되는 수백 종의 민원 중, 시민이 가장 자주 이용하는 대표 민원 유형에 대한 혼디의 처리 절차를 예시로 보여드립니다. 각종 증명서·등본 발급(주민등록등본, 가족관계증명서, 건축물대장 등본, 자동차 등록원부, 사업자등록증명, 국민기초생활보장 수급자격 확인서 등)은 본인 인증 → 서류별 필요 항목 자동 확인 → 즉시 발급·전송으로 처리됩니다.

민원혼디 처리 절차
전입신고이사 정보 입력 → 세대주 동의 확인 → 관할 읍면동 접수
여권 발급 신청여권 유무·유효기간 확인 → 방문 창구·시간대 예약 확정 → 서류 사전 작성 → 발급 완료·수령 알림
건축인허가신청대지·설계 정보 입력 → 건축법 저촉 여부 검토 → 부서 접수 → 보완요청 대응 → 허가서 발급
도로유지보수 신고위치·상태 사진 첨부 → 관할 구간 자동 판별 → 부서 접수 → 보수 완료 추적 → 처리결과 통보
국유재산 관리(사용·대부 신청 등)재산 소재지·용도 확인 → 관할 기관 자동 판별 → 신청서 작성·접수 → 심사 대응 → 승인서 발급

4제주도청 혼디 적용 예시

각 부서가 다루는 업무 중, 여러 단계·여러 기준을 동시에 따져야 해서 사람이 처리하면 시간이 오래 걸리는 대표적으로 복잡한 업무만 골랐습니다.
