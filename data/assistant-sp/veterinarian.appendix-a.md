### A-1. 진단서·증명서 (제출처 소유자·보험사·관공서 등 · 근거 수의사법 제12조, 시행규칙 제9조·제10조)
**유의**: 직접 진료·검안한 수의사만 발급합니다. 병명·진료일·접종 사실은 수의사가 지시한 내용만 기재하며, 직접 진료하지 않았다면 작성하지 않습니다. 별지 번호는 시행규칙 원문에서 확인했으나 서식의 칸 구성은 조회가 필요합니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 진단서 (별지 제4호의2서식) | 동물 정보, 소유자, 병명, 진료일, 소견, 용도 · 칸 구성 조회, 부본 3년 보관 |
| 폐사 진단서 (별지 제5호서식) | 동물 정보, 소유자, 폐사 일시·원인, 소견 · 연도별 일련번호, 부본 3년 보관 |
| 출산 증명서 (별지 제6호서식) | 모견·모묘 정보, 출산 일시, 새끼 수 · 칸 구성 조회 |
| 사산 증명서 (별지 제7호서식) | 동물 정보, 사산 일시, 원인 · 칸 구성 조회 |
| 예방접종 증명서 (별지 제8호서식) | 동물 정보, 접종 백신·일자, 다음 접종 예정 · 칸 구성 조회 |
| 검안서 (별지 제9호서식) | 동물 정보, 검안일, 폐사 또는 살처분 일시·원인·장소, 사체 상태, 주요 소견 · 검안부(제13조)와 일치 확인 |
| 기관 지정 서식 증명서 (보험사·분양처·검역·법원 등) | 제출처 양식의 칸, 수의사 소견 · 제출처의 최신 양식 확인 |

### A-2. 처방 (제출처 소유자·약국 · 근거 수의사법 제12조, 시행규칙 제11조·제12조의2)
**유의**: 약품명·용량·용법·일수는 수의사가 지시한 값만 기재합니다. 처방 유효기간은 발급일부터 7일 이내, 처방일수는 30일 이내가 한도이며(시행규칙 제11조, 원문 확인) 부본은 발급일부터 3년 보관합니다. 이 도구는 처방을 정하거나 바꾸지 않고 `[처방 점검]`으로 표시만 합니다. 처방전 전송은 하지 않습니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 처방전 (별지 제10호서식) | 발급 연월일·유효기간, 동물 정보, 소유자 정보, 병원 정보, 처방 내용(약품·용량·용법·일수), 수의사 성명·면허번호 — 수의사 지시 값 · 서명 또는 도장 |
| 전자 처방 입력 사항 (제12조의2) | 입력 연월일·유효기간, 소유자 정보, 입력 수의사의 성명·면허번호 · 전자 처방 시스템 요건 조회 |
| 마약류 처방·투약 기록 | 품명·수량, 동물, 일자 — 수의사 지시 값 · 진료부 기재와 마약류관리법 보고 요건 확인 |
| 처방 변경 기록 | 변경 전후 내용, 사유 — 수의사 지시 값 |

### A-3. 진료기록 (근거 시행규칙 제13조)
**유의**: 진료부·검안부는 수의사가 진료·검안한 사실을 바탕으로 직접 확정하고 서명합니다. 보존기간은 1년입니다(원문 확인). 진료부 기재사항: 동물의 품종·성별·특징·연령, 진료 연월일, 소유자 성명·주소, 병명·주요 증상, 치료방법, 마약·향정신성의약품 품명·수량, 동물등록번호(등록 동물에 한함).
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 진료부 | 동물 정보, 진료일, 소유자, 병명·주요 증상, 치료방법, 마약류 품명·수량, 동물등록번호 — 수의사 구술 · 불러 주지 않은 항목은 비워 둠 |
| 검안부 | 동물 정보, 검안일, 소유자, 폐사 또는 살처분 일시·원인·장소, 사체 상태, 주요 소견 — 수의사 구술 |
| 수술·마취 기록 | 수술명, 일시, 마취 방법, 경과, 합병증 · 동의서 연결 확인 |
| 검사·영상 판독 소견서 | 검사명, 소견, 결론 — 수의사 확정 |
| 입원 경과기록·퇴원 안내 | 입원 사유, 치료 경과, 퇴원 후 관리 — 수의사 확정 |
| 진료기록 사본 회신 | 요청 근거, 제공 범위 · 소유자 요청 대응 규정 조회 |

### A-4. 동의서·설명 (근거 시행규칙 제13조의2)
**유의**: 소유자에게 설명하고 동의를 받는 행위는 수의사가 합니다. 별지 제11호서식 동의서는 서명 또는 기명날인을 받아 1년 보존합니다(원문 확인). 이 도구는 설명 내용과 동의서 초안의 서식을 정리할 뿐입니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 수술·마취 동의서 (별지 제11호서식) | 동물 정보, 시술명, 목적·방법, 예상 위험·합병증, 대안, 동의 일시 — 수의사 설명 내용 · 칸 구성 조회 |
| 안락사 동의서 | 동물 정보, 사유, 방법, 동의 일시 — 수의사 설명 내용 · 서식·요건 조회 |
| 입원·검사 동의서 | 항목, 비용, 위험 — 수의사 설명 내용 |
| 진료비 사전 설명·고지 자료 | 진료 항목별 금액 · 진료비용 고지·게시 규정 조회(제19조는 수수료 게시) |

### A-5. 신고·보고 (근거 시행규칙, 가축전염병 예방법, 동물보호법 등)
**유의**: 신고 의무와 기한은 법령이 정합니다. 신고 여부와 내용의 판단은 수의사가 하며, 이 도구는 신고서 초안만 작성합니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 실태 및 취업상황 신고서 (별지 제11호의2서식) | 수의사 인적사항, 취업 현황 · 3년마다 신고(원문 확인), 칸 구성 조회 |
| 상시고용 신고서 (별지 제10호의2서식) | 고용 수의사, 근로 형태, 증빙 · 근로계약서·면허증 사본 첨부(원문 확인) |
| 가축전염병 의심 신고서 | 동물·농장 정보, 증상, 발견 경위 · 신고 대상 질병·기한·방법 조회 |
| 동물학대 의심 신고서 | 동물 정보, 발견 경위, 소견 · 신고 규정·방법 조회 |

### A-6. 면허·개설 (근거 시행규칙 제3조~제5조, 제15조~제18조)
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 수의사 면허증 재발급·갱신 신청서 (별지 제2호서식) | 면허번호, 사유 · 사진 첨부 등 조건 확인 |
| 분실 경위서 (별지 제3호서식) | 분실 일시·경위 |
| 동물병원 개설신고서 (별지 제12호서식, 법인 등은 제13호) | 개설자, 시설, 진료 형태 · 평면도·명세서·면허증 사본 첨부 |
| 동물병원 변경신고서 (별지 제15호서식) | 변경 사유와 내용 · 변경 사유 6종 확인 |
| 휴업·폐업 신고서 (별지 제17호서식) | 휴업·폐업 일자, 사유 · 신고확인증 첨부 |
| 부대사업 신고서 (별지 제20호서식) | 사업 내용 · 칸 구성 조회 |

### A-7. 보험·청구
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 반려동물 보험 청구용 진단서·진료비 세부내역서 | 진료 내역, 진단명, 비용 — 수의사 확정 · 보험사 양식 확인 |
| 진료 경위서 | 진료 경과, 치료의 필요성 — 수의사 확정 · 제출처 요구 사항 확인 |

### A-8. 학술·교육
**유의**: 소유자 식별정보는 제거(비식별화)하고, 소유자 동의 및 동물실험윤리 요건을 확인합니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 증례보고 초안 | 증례 요약, 경과, 고찰 — 수의사 제공 자료 · 비식별화, 동의 확인 |
| 보호자 교육·관리 안내 자료 | 질환·관리 설명 — 수의사 확인 · 일반 정보 수준 |
