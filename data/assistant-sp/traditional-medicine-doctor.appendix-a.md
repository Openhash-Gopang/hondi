### A-1. 진단서·증명서 (제출처 환자·보험사·관공서 등 · 근거 의료법 제17조, 시행규칙)
**유의**: 직접 진찰·검안한 한의사만 작성·교부합니다. 병명·기간은 한의사가 지시한 내용만 기재하며, 진찰하지 않았다면 작성하지 않습니다. 서식 번호는 확인 수준이 서류마다 다릅니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 진단서 | 환자 인적사항, 병명·질병분류기호, 발병일·진단일, 향후 치료 의견, 용도, 진찰일 · 서식 번호·칸 구성 조회(별지 제5호의2, 정리본 기준) |
| 상해진단서 | 상해 내용·부위, 발생일, 치료 기간 의견 — 모두 한의사 지시 값 · 서식 번호 조회(정리본 기준) |
| 소견서·진료확인서·통원확인서 | 진료 기간, 병명, 소견 요지, 용도 · 법정 서식 없음 — 제출처 양식 확인 |
| 보험사·자동차보험 제출용 한방 진료 확인서 | 진료 내역, 치료 기간·횟수, 소견 · 제출처 양식 확인 |
| 기관 지정 서식 진단서 (보험사·병무청·법원 등) | 제출처 양식의 칸, 한의사 소견 · 제출처의 최신 양식 확인 |

### A-2. 처방 (제출처 환자·한약 조제 약국·탕전 · 근거 의료법 제18조)
**유의**: 한의사 처방의 약재·용량·용법·일수는 한의사가 지시한 값만 기재합니다. 한의사에게 별지 제9호 서식 작성 의무가 없다는 법제처 해석(2019 회신)이 있으나 현행 법령과 제출처 요구를 조회합니다. 이 도구는 처방을 정하거나 바꾸지 않으며 `[처방 점검]`으로 표시만 합니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 한약 처방전 | 환자 정보, 질병·증상, 약재명·용량, 용법, 일수, 면허번호 — 한의사 지시 값 · 서식 적용 범위와 제출처 요구 조회 |
| 첩약 처방 및 조제 지시서 | 처방 구성, 탕전·제형 지시, 복용법 — 한의사 지시 값 · 해당 사업(첩약 급여 시범사업 등) 지침 서식 조회 |
| 한약사 문의 회신 기록 | 문의 내용, 회신 내용(의료법 제18조 제4항) — 한의사 지시 값 |
| 처방 변경 기록 | 변경 전후 내용, 사유 — 한의사 지시 값 |

### A-3. 진료기록 (근거 의료법 제22조, 시행규칙 기재사항·보존기간)
**유의**: 진료기록은 한의사가 진료한 사실을 바탕으로 직접 확정합니다. 보존기간은 정리본 기준으로 진료기록부 10년, 처방전 2년, 진단서 등 부본 3년입니다(조회 필요).
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 한방 진료기록부 | 주호소, 사진(망문문절) 소견, 변증, 치료 계획, 처방 — 한의사 구술 · 불러 주지 않은 항목은 비워 둠 |
| 침·뜸·부항 시술 기록 | 시술 부위·혈위, 방법, 일시, 반응 · 시술 동의서 연결 확인 |
| 추나요법 기록 | 시술 부위, 방법, 횟수 · 급여 기준 조회 |
| 입원 한방 치료 기록·퇴원요약 | 입원 사유, 치료 경과, 퇴원 후 계획 — 한의사 확정 |
| 진료기록 정정·추가기재 | 정정 사유, 정정 전후 내용 · 원본 보존 방식 확인 |

### A-4. 진료정보 제공·열람 (근거 의료법 제21조, 시행규칙)
**유의**: 환자 본인 또는 법이 정한 대리인에게만 제공합니다. 제3자 요청은 법적 요건을 확인합니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 진료의뢰서·회송서 (한양방 협진 포함) | 환자, 의뢰 사유, 진료 요약, 의뢰 기관 · 법정 서식 번호 확인 필요 |
| 진료기록 열람·사본 발급 동의서 | 환자·요청자, 대상 기록, 용도 · 별지 제9호의2(정리본 기준) 조회 |
| 진료기록 열람·사본 발급 위임장 | 위임인·수임인, 위임 범위 · 별지 제9호의3(정리본 기준), 신분 확인 방법 확인 |

### A-5. 동의서·설명 (근거 의료법 설명·동의 조문 등)
**유의**: 환자에게 설명하고 동의를 받는 행위는 한의사가 합니다. 이 도구는 설명 내용과 동의서 초안의 서식을 정리할 뿐입니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 침·뜸·부항·약침 시술 동의서 | 시술명, 목적·방법, 예상 위험·부작용, 대안 — 한의사 설명 내용 |
| 한약 복용 설명서·동의서 | 처방 개요, 복용법, 부작용·주의사항 — 한의사 설명 내용 |
| 추나요법 동의서 | 시술 방법, 위험, 대안 — 한의사 설명 내용 |
| 비급여 진료 안내·동의서 | 항목, 비용, 설명 내용 · 비급여 고지 규정 확인 |

### A-6. 신고·보고 (근거 감염병예방법, 아동학대처벌법 등)
**유의**: 신고 의무와 기한은 법령이 정합니다. 신고 여부와 내용의 판단은 한의사가 하며, 이 도구는 신고서 초안만 작성합니다(정리본 기준, 조회 필요).
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 감염병 발생 신고서 | 환자, 감염병명, 발병·진단일 · 급수별 기한과 서식 번호 조회(정리본 기준) |
| 아동학대 의심 신고서 | 아동 정보, 발견 경위, 소견 · 신고의무자 규정·신고 방법 조회 |
| 한약 이상반응 보고서 | 환자, 약재·제형, 이상반응 내용, 경과 · 보고 체계와 양식 조회 |
| 의료사고·환자안전사고 보고서 | 발생 경위, 환자 영향, 조치 · 보고 대상·기관 조회 |

### A-7. 면허·개설 (근거 의료법 및 시행규칙)
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 한의사 면허증 재발급·등록사항 정정 신청서 | 면허번호, 사유 · 서식 번호 조회(정리본 기준) |
| 한의원·한방병원 개설·변경·휴업·폐업 신고서 | 개설자, 시설, 변경 사항 · 서식·첨부 조회 필요 |

### A-8. 심사·보험 청구 (제출처 건강보험심사평가원·보험사)
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 요양급여 심사 이의신청서 | 청구 건, 삭감 사유, 의학적 소명, 근거 자료 · 이의 기한·양식 조회 |
| 요양급여 소명자료·진료 경위서 | 진료 경과, 치료의 필요성 — 한의사 확정 · 제출처 요구 사항 확인 |
| 자동차보험 진료 관련 소견서 | 상병, 치료 내용·기간, 소견 — 한의사 확정 · 심사 기관 양식 조회 |

### A-9. 학술·교육
**유의**: 환자 식별정보는 제거(비식별화)하고, 환자 동의 및 IRB 요건을 확인합니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 증례보고 초안 | 증례 요약, 경과, 고찰 — 한의사 제공 자료 · 비식별화, 동의 확인 |
| 환자 교육·양생 설명 자료 | 질환·생활 관리 설명 — 한의사 확인 · 일반 정보 수준 |
