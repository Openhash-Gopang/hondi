### A-1. 진단서·증명서 (제출처 환자·보험사·관공서 등 · 근거 의료법 제17조, 시행규칙)
**유의**: 직접 진찰·검안한 치과의사만 작성·교부합니다. 병명·치료 부위·기간은 치과의사가 지시한 내용만 기재하며, 진찰하지 않았다면 작성하지 않습니다. 서식 번호는 확인 수준이 서류마다 다릅니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 진단서 | 환자 인적사항, 병명·질병분류기호, 발병일·진단일, 향후 치료 의견, 용도, 진찰일 · 의사·치과의사 공통 서식(별지 제5호의2, 정리본 기준) 사용 여부 조회 |
| 상해진단서 | 상해 내용·치아 부위, 발생일, 치료 기간 의견 — 모두 치과의사 지시 값 · 서식 번호 조회(정리본 기준) |
| 치아치료확인서·치료 확인서(보험사 제출용) | 치료 치아(치식), 치료 내용, 치료일, 비용 · 보험사별 양식 확인 |
| 소견서·진료확인서·통원확인서 | 진료 기간, 병명, 소견 요지, 용도 · 법정 서식 없음 — 제출처 양식 확인 |
| 기관 지정 서식 진단서 (보험사·병무청·법원 등) | 제출처 양식의 칸, 치과의사 소견 · 제출처의 최신 양식 확인 |

### A-2. 처방 (제출처 환자·약국 · 근거 의료법 제18조, 시행규칙 제12조)
**유의**: 약품명·용량·용법·일수는 치과의사가 지시한 값만 기재합니다. 이 도구는 처방을 정하거나 바꾸지 않으며, 중복·상호작용·용량 범위·특수 환자군은 `[처방 점검]`으로 표시만 합니다. 처방전 전송·조제 의뢰는 하지 않습니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 처방전 | 환자 정보, 질병분류기호, 약품명·1회 투약량·1일 투여횟수·총 투약일수, 사용기간, 면허번호 — 치과의사 지시 값 · 별지 제9호 서식·칸 조회(정리본 기준) |
| 마약류 처방 확인 자료 | 해당 약물, 환자, 용량·기간 — 치과의사 지시 값 · 마약류관리법상 처방·보고 요건 확인 |
| 처방 변경·사후 연락 기록 | 변경 전후 내용, 사유, 환자 안내 — 치과의사 지시 값 |

### A-3. 진료기록 (근거 의료법 제22조, 시행규칙 기재사항·보존기간)
**유의**: 진료기록은 치과의사가 진료한 사실을 바탕으로 직접 확정합니다. 보존기간은 정리본 기준으로 진료기록부·수술기록 10년, 검사기록·영상물 및 소견서 5년, 처방전 2년, 진단서 등 부본 3년입니다(조회 필요).
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 치과 진료기록부 (SOAP) | 주호소, 병력, 구강 진찰 소견, 평가(진단), 계획(치료·처방·교육), 치식·부위 — 치과의사 구술 · 불러 주지 않은 항목은 비워 둠 |
| 시술·수술기록 (발치·임플란트·치주수술 등) | 시술명, 일시, 부위, 마취, 소견, 합병증 · 동의서 연결 확인 |
| 방사선 영상 판독 소견 | 촬영 종류, 소견, 결론 — 치과의사 확정 |
| 치료계획서 (보철·교정·임플란트) | 진단, 치료 단계, 예상 기간·비용 — 치과의사 지시 값 · 환자 설명 내용과 일치 확인 |
| 진료기록 정정·추가기재 | 정정 사유, 정정 전후 내용 · 원본 보존 방식 확인 |

### A-4. 진료정보 제공·열람 (근거 의료법 제21조, 시행규칙)
**유의**: 환자 본인 또는 법이 정한 대리인에게만 제공합니다. 제3자 요청은 법적 요건을 확인하고, 제공 여부는 치과의사(의료기관)가 결정합니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 진료의뢰서·회송서 | 환자, 의뢰 사유, 진료 요약, 의뢰 기관 · 법정 서식 번호 확인 필요 |
| 진료기록 열람·사본 발급 동의서 | 환자·요청자, 대상 기록, 용도 · 별지 제9호의2(정리본 기준) 조회 |
| 진료기록 열람·사본 발급 위임장 | 위임인·수임인, 위임 범위 · 별지 제9호의3(정리본 기준), 신분 확인 방법 확인 |
| 보험사 제출용 진료기록 사본 회신 | 요청 근거, 제공 범위 · 법적 요건 확인 |

### A-5. 동의서·설명 (근거 의료법 설명·동의 조문 등)
**유의**: 환자에게 설명하고 동의를 받는 행위는 치과의사가 합니다. 이 도구는 설명 내용과 동의서 초안의 서식을 정리할 뿐이며, 설명했다는 사실을 대신 기록하지 않습니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 발치·구강외과 수술 동의서 | 시술명, 목적·방법, 예상 위험·합병증, 대안 — 치과의사 설명 내용 |
| 임플란트·보철 치료 동의서 | 치료 단계, 위험, 대안, 비용 — 치과의사 설명 내용 |
| 교정치료 동의서 | 치료 기간, 위험, 유지 장치, 비용 — 치과의사 설명 내용 |
| 마취·진정 동의서 | 마취 방법, 위험, 대안 — 치과의사 설명 내용 |
| 비급여 진료 안내·동의서 | 항목, 비용, 설명 내용 · 비급여 고지 규정 확인 |

### A-6. 신고·보고 (근거 감염병예방법, 아동학대처벌법, 마약류관리법 등)
**유의**: 신고 의무와 기한은 법령이 정합니다. 신고 여부와 내용의 판단은 치과의사가 하며, 이 도구는 신고서 초안만 작성합니다(정리본 기준, 조회 필요).
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 감염병 발생 신고서 | 환자, 감염병명, 발병·진단일 · 급수별 기한과 서식 번호 조회(정리본 기준) |
| 아동학대 의심 신고서 | 아동 정보, 발견 경위, 소견 · 신고의무자 규정·신고 방법 조회 |
| 마약류 취급·투약 보고 자료 | 품목, 수량, 환자, 일자 · 마약류통합관리시스템 보고 요건 조회 |
| 의료사고·환자안전사고 보고서 | 발생 경위, 환자 영향, 조치 · 보고 대상·기관 조회 |

### A-7. 면허·개설 (근거 의료법 및 시행규칙)
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 치과의사 면허증 재발급·등록사항 정정 신청서 | 면허번호, 사유 · 서식 번호 조회(정리본 기준) |
| 치과의원·치과병원 개설·변경·휴업·폐업 신고서 | 개설자, 시설, 변경 사항 · 서식·첨부 조회 필요 |

### A-8. 심사·보험 청구 (제출처 건강보험심사평가원·보험사)
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 요양급여 심사 이의신청서 | 청구 건, 삭감 사유, 의학적 소명, 근거 자료 · 이의 기한·양식 조회 |
| 요양급여 소명자료·진료 경위서 | 진료 경과, 치료의 필요성 — 치과의사 확정 · 제출처 요구 사항 확인 |

### A-9. 학술·교육
**유의**: 환자 식별정보는 제거(비식별화)하고, 환자 동의 및 IRB 요건을 확인합니다.
| 서류 | 핵심 기재 · 첨부·확인 |
|---|---|
| 증례보고 초안 | 증례 요약, 경과, 고찰 — 치과의사 제공 자료 · 비식별화, 동의 확인 |
| 환자 교육·구강관리 설명 자료 | 질환·치료 설명 — 치과의사 확인 · 일반 의학 정보 수준 |
