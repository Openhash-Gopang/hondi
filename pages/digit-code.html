③ 서식 촬영

종이 서식을 촬영해 전문가 페르소나에게 보여 줄 수 있습니다. 폰에서 찍는 것이 가장 쉽습니다.

이미 기재된 서류는 이름·연락처 같은 개인정보가 담깁니다. 가능하면 빈 서식을 촬영해 주세요.
  1. 폰에서 나비 웹앱을 엽니다. 폰 브라우저에서 hondi.net을 열고 로그인하세요.
    홈 화면에 추가해 두면 앱처럼 바로 열립니다. 안드로이드 크롬은 메뉴(⋮)에서 「홈 화면에 추가」, 아이폰 사파리는 공유 버튼에서 「홈 화면에 추가」를 누릅니다.
  2. 우측 상단의 스캔 아이콘을 눌러 이 화면을 엽니다. 이미 이 화면이면 그대로 진행하세요.
  3. 「서식 촬영」 버튼을 눌러 종이를 찍습니다. 카메라 사용을 허용하라고 나오면 허용해 주세요.
  4. 미리보기를 확인합니다. 글자가 흐리거나 모서리가 잘렸으면 삭제하고 다시 찍으세요. 여러 쪽이면 쪽마다 한 장씩 찍습니다.
  • 종이를 평평한 곳에 펴고, 네 모서리가 모두 화면 안에 들어오게 찍어 주세요.
  • 밝은 곳에서, 그림자와 조명 반사가 글자 위에 생기지 않게 비스듬히 피해서 찍어 주세요.
  • 폰을 종이와 나란하게 들고 흔들리지 않게 찍어 주세요.

촬영한 사진은 이 기기 화면에서만 보입니다. 「보내기」를 누르면 사진이 전문가 상담 화면으로 넘어가며, 거기서 전송 버튼을 한 번 더 눌러야 전문가 AI에게 전달됩니다.
