법무사 보조 AI는 등기·공탁·법원 제출 서류 등 법무사 업무의 초안을 만들고 검토 포인트를 정리해 주는 도구입니다. 현재 버전은 서류를 제출·서명·대리하지 않으며(dpaper 승인 후 사람의 최종 승인을 전제로 제출·납부 대행으로 확장할 계획), 법무사의 최종 검토와 승인 아래에서만 쓰입니다.

모든 직역 AI의 공통 설계

  • 모델: 오픈소스 중소형 LLM(예: Gemma 4 31B)을 해당 직역 전문가의 업무 보조에 특화해 조정합니다. 해외 거대 LLM에 호출하지 않습니다.
  • 운영: 국내 서버에 설치해 서비스를 제공하며, 업무 자료가 해외로 나가지 않습니다.
  • dpaper API 승인 후의 계획: 승인되면 서류 작성, 제출, 수수료 납부까지 AI가 대행하고, 사람(자격자)은 최종 검토와 승인을 맡습니다.

현재는 dpaper 승인 전이므로 제출·납부는 연동되지 않았고 사람이 직접 합니다. 제출·납부 대행은 관련 법령(직역별 업무 범위, 무자격 대리 금지 등)의 검토와 승인 절차를 거친 뒤에 시작하며, 그 전에는 이 문서의 대행 기능을 제공하지 않습니다.

상세 보기(hondi.net): 법무사 보조 AI · 서류 작성하기 · 나비웹 홈. 해당 페이지는 테스트 단계의 화면입니다.

안내 이 문서는 서비스 소개서이며 투자 권유나 입찰 공고가 아닙니다. 지분 매수에 관한 사항은 별도의 지분 매수 제안서(초안)를 따릅니다. 아래 '차별점'은 설계와 운영 규칙상의 차이를 설명한 것이며, 다른 서비스보다 성능이 우수하다는 것을 실측으로 입증한 내용이 아닙니다. 성능·정확도는 제3자 검증 전이며, 각 서비스는 테스트 단계입니다. 이 서비스는 해당 직역의 자격을 갖지 않으며, 모든 산출물은 자격자가 검토·확정해야 하는 초안입니다.

2. 이 서비스가 하는 일

  • 서류 목적과 제출처를 묻고 부록 A 서류 목록에서 후보 1~3개를 근거와 함께 제시
  • 서식 DB에서 기관 서식을 조회하고, 없으면 이용자가 승인한 항목으로 새 서식을 구성(법정 서식이 아님을 표시)
  • 누락 항목을 표로 정리하고 빠진 것만 한 번에 3개 이내로 질문
  • 주민등록번호·계좌번호는 본문에 쓰지 않고 [법무사 직접 기재] 자리표시자로 남김
  • 제출 패키지(제출처·접수 방식·첨부·제출 전 점검)와 수수료 항목을 조회 확인분만 정리
  • 제출 결과(접수번호·일시·납부액)를 이용자가 알려 준 만큼만 기록

3. 범용 AI와 다른 점

범용 AI 챗봇에서 흔한 방식법무사 보조 AI의 설계
서류 한 장을 바로 써 줌서식을 정하고 이용자 승인(W-2)을 받은 뒤에만 본문 작성. 승인은 명시적 발화로만 통과하며 AI가 대신 승인하지 않음
법령·서식 번호·수수료를 기억에 의존해 단정법정 서식 여부·서식 번호·수수료·기한은 웹 조회로 확인한 것만 확정처럼 쓰고, 나머지는 [확인 필요]로 표시
빠진 정보를 그럴듯하게 채움접수번호·납부액·결과는 이용자 제공 자료에서만 옮겨 적고 모르는 칸은 [미확인]
출처가 섞임이용자 진술(F) / 조회 확인(V, 출처·조회일) / 도구의 추론(I)을 구분
제출까지 대행하는 듯한 표현현재는 제출·납부·서명·날인을 사람이 하도록 고정. dpaper 승인 후에는 AI가 제출·납부를 실행하고 사람이 최종 승인하는 구조로 확장 계획(법령 검토 후)
새 서식이 대화마다 사라짐개인·사안 값을 모두 지운 빈 서식만 저장 제안. 이용자가 동의해야 저장

4. 다른 직역 AI와 다른 점

  • 등기·공탁·법원 제출 서류 중심의 서류 목록(부록 A)과 제출처·관할 확인 흐름이 법무사 업무에 맞춰져 있음
  • 변호사 보조 AI는 소송 전략·법률 쟁점, 행정사 보조 AI는 인허가·민원 서류, 이 서비스는 법무사 업무 범위의 서류 작성과 제출 준비에 초점
  • 범위 밖 요청은 부록 B에서 해당 직역으로 안내([REFER_LAWYER] 사용 기준 별도)

6. 현재 상태와 한계

  • 테스트 단계. dpaper API는 아직 승인·개통되지 않아 전자 제출은 연동되지 않음
  • 판단 구조는 K-Law v15.1 기준이며, 제3자 검증 전 단계
  • 조문·수치·기한은 인용 시 확인 필요 표시를 동반하며, 최종 확인은 법무사가 함
  • 법무사법 등 현행 법령의 확인 범위는 서비스 내부 조회 기준
