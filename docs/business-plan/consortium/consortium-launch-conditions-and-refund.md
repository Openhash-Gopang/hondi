# 나비 법인 주식 매각: 개시 조건과 환불 (초안)

## 1. 왜 별도 문서가 필요한가

나비웹이 직역별 법인의 주식 5%(필요하면 추가 5%)를 개시 전에 매각하고, 대금은 나비웹이 **국산 LLM 서버 구축 비용에 전액** 씁니다. 개시하지 못했을 때의 환불 재원은 구축한 서버의 **매각 자금**입니다. 초기 사업은 정부 지원 GPU를 쓰므로 기준 가입자 수(잠재적 가입자 수, 곧 직역별 시장 규모의 10%)를 확보하기 전까지는 대개의 투자 재원을 서버 구축에 쓰지 않고, 그 뒤에 서버를 구매하면, 환불은 아직 쓰지 않은 대금으로 하고 이미 구매한 서버가 있으면 그 매각 자금으로 하므로 이 위험을 줄일 수 있습니다. 다만 **정부 GPU 지원은 사업 개시 전에 확보해야 할 선결 과제**이며 그 조건이 확정되어야 하고, 이미 구매한 서버의 매각 대금이 낙찰 대금에 못 미칠 수 있으므로, 개시 조건과 환불의 한도·시기·책임 주체를 입찰 전에 정해 공개해야 합니다.

## 2. 정해야 할 항목

### 2.1 개시 조건

| 항목 | 검토할 내용 | 상태 |
|---|---|---|
| **개시의 정의** | 서비스 개시를 무엇으로 볼지(서버 구축 완료, 면허 인증 연동 완료, 첫 이용자 가입 등) | 미확정 |
| **개시 기한** | 입찰 대금 납부일부터 개시까지의 기한과 연장 사유·횟수 | 미확정 |
| **파일럿 프로젝트** | 종량제 비중 등 매출 가정을 확인하는 파일럿을 초기 6~9개월(정부 지원 GPU 기간)에 하고, 비용은 첫 5% 매각 대금 전액으로 충당합니다. 기준 가입자 수(잠재적 가입자 수, 곧 직역별 시장 규모의 10%)를 확보하기 전까지는 대개의 투자 재원을 서버 구축에 쓰지 않습니다. 정할 것: 범위, 기간, 성공 기준 | 미확정 |
| **서버 구축 시점** | 초기 사업은 정부 지원 GPU를 쓰므로 기준 가입자 수(잠재적 가입자 수, 곧 직역별 시장 규모의 10%)를 확보하기 전까지는 대개의 투자 재원을 서버 구축에 쓰지 않습니다. 정부 지원 GPU 기간(6~9개월) 안에 기준 가입자 수(잠재적 가입자 수의 10%)에 못 미치면 개시를 중단하고 환불할지 서버를 구매해 계속할지를 나비웹과 해당 자회사 이사진의 연석 회의로 정하고 최종 판단은 나비웹이 합니다. 미사용 대금은 나비웹이 관리합니다. 파일럿이 실패하면 fine-tuning 결과물(직역별 LLM 최소 10종)과 특허 출원(최소 10건 이상)을 공개 매각해 초기 투자자를 보상합니다. | 미확정 |
| **투자자 보상** | 파일럿에 쓴 대금은 돌려주지 않고, 개시하지 못하면 미사용 대금, 서버 매각 자금, fine-tuning 결과물(직역별 LLM 최소 10종)과 특허 출원(최소 10건 이상)의 공개 매각 대금으로 초기 투자자를 보상합니다. 보상액이 투자액에 못 미쳐도 시가보다 할인된 가격으로 샀으므로 보상이 완료된 것으로 봅니다(위험과 수익의 대응). 이 점은 입찰 공고에 명시합니다. | 미확정 |
| **선행 조건** | 법률·세무 검토 결과, 직역 단체 협의, **정부 GPU 지원 확보(최장 9개월, 조건 미확정; 사업 개시 전에 확보해야 할 선결 과제)**, 면허 인증 연동 | 미확정 |
| **입찰 개시 조건** | 입찰 공고 전에 충족해야 할 사항(이 문서의 확정, 전문가 검토 완료 등) | 미확정 |

### 2.2 환매·환불

| 항목 | 검토할 내용 | 상태 |
|---|---|---|
| **환불 사유** | 개시 기한 도과, 선행 조건 미충족, 입찰 공고와 다른 대금 사용 등 | 미확정 |
| **환불 방식** | 낙찰가 전액 환불인지, 이자나 수수료를 어떻게 할지, 나비웹의 주식 환매(매수)로 구성할지 | 미확정 |
| **환불 재원과 책임 주체** | 환불 재원은 아직 쓰지 않은 대금(서버 구축을 기준 가입자 수 확보 뒤로 미루는 경우)과 이미 구매한 서버의 매각 자금입니다. 서버 구매 시점과 구매 가능 한도, 서버 처분 절차와 기한, 처분 대금이 낙찰 대금에 못 미칠 때의 처리(비례 환불, 나비웹의 다른 자금으로 보전 여부), 정부 지원 GPU처럼 처분할 수 없는 자산을 제외하는 방식, 환불 책임을 나비웹이 진다는 점 | 미확정 |
| **환불 시기** | 사유 발생일부터 환불까지의 기한 | 미확정 |
| **환불 이후의 지분** | 환매 뒤 나비웹이 다시 100%를 보유하는지, 법인의 해산 여부 | 미확정 |

| 항목 | 검토할 내용 | 상태 |
|---|---|---|
| **대금 보관** | 입찰 대금을 개시 전까지 에스크로 등 별도 관리할지, 서버 구축 단계별로 인출할지 | 미확정 |

| **독립 검토** | 주주가 요청하면 받는 독립적 검토(감사)의 범위와 비용 부담 | 미확정 |

## 3. 이 문서가 확정되는 방식

1. 법률·세무 전문가 검토 요청서(공통 질문 13번)에 대한 검토 결과를 받습니다.
2. 위 항목의 안을 확정해 주주 간 계약, 정관, 입찰 공고에 반영합니다.
3. 확정된 내용은 입찰 공고 전에 직역별 참여 대상에게 공개합니다.

## 4. 한계

- 이 문서의 어떤 항목도 환불을 약속하지 않습니다. 확정되기 전에는 입찰을 열지 않으므로 누구에게도 낼 대금이나 환불할 의무가 생기지 않습니다.
- 정부 지원 GPU로 서버 구매를 늦추면 위험이 줄지만, 지원을 확보하지 못하거나 지원 기간 안에 개시 여부를 판정하지 못하면 줄지 않습니다. 이미 구매한 서버가 있다면 서버의 중고 가치 하락, 처분에 걸리는 시간, 처분 대금이 낙찰 대금에 못 미칠 위험이 핵심입니다. 정부 지원 GPU는 처분할 수 없을 수 있어 환불 재원에서 빠집니다.
