## 1. 왜 별도 문서가 필요한가

나비웹이 직역별 법인의 주식 5%(필요하면 추가 5%)를 개시 전에 매각하고, 대금은 나비웹이 **국산 LLM 서버 구축 비용에 전액** 씁니다. 대금이 서버 구축에 쓰이고 나면 서비스가 개시되지 않아도 돌려줄 돈이 남아 있지 않으므로, 개시 조건과 환불의 재원·시기·책임 주체를 입찰 전에 정해 공개해야 합니다.

## 2. 정해야 할 항목

### 2.1 개시 조건

| 항목 | 검토할 내용 | 상태 |
|---|---|---|
| **개시의 정의** | 서비스 개시를 무엇으로 볼지(서버 구축 완료, 면허 인증 연동 완료, 첫 이용자 가입 등) | 미확정 |
| **개시 기한** | 입찰 대금 납부일부터 개시까지의 기한과 연장 사유·횟수 | 미확정 |
| **선행 조건** | 법률·세무 검토 결과, 직역 단체 협의, 정부 GPU 지원 확보(최장 9개월, 조건 미확정), 면허 인증 연동 | 미확정 |
| **입찰 개시 조건** | 입찰 공고 전에 충족해야 할 사항(이 문서의 확정, 전문가 검토 완료 등) | 미확정 |

| 항목 | 검토할 내용 | 상태 |
|---|---|---|
| **환불 사유** | 개시 기한 도과, 선행 조건 미충족, 입찰 공고와 다른 대금 사용 등 | 미확정 |
| **환불 방식** | 낙찰가 전액 환불인지, 이자나 수수료를 어떻게 할지, 나비웹의 주식 환매(매수)로 구성할지 | 미확정 |
| **환불 재원과 책임 주체** | 대금이 서버 구축에 전액 쓰이므로 환불 재원을 어디서 마련할지(나비웹의 다른 자금, 서버 자산의 처분, 정부 지원 등)와 환불 책임을 나비웹이 진다는 점 | 미확정 |
| **환불 시기** | 사유 발생일부터 환불까지의 기한 | 미확정 |
| **환불 이후의 지분** | 환매 뒤 나비웹이 다시 100%를 보유하는지, 법인의 해산 여부 | 미확정 |

## 3. 이 문서가 확정되는 방식

1. 법률·세무 전문가 검토 요청서(공통 질문 13번)에 대한 검토 결과를 받습니다.
2. 위 항목의 안을 확정해 주주 간 계약, 정관, 입찰 공고에 반영합니다.
3. 확정된 내용은 입찰 공고 전에 직역별 참여 대상에게 공개합니다.
