# 나비 컨소시엄 공동 출자 1페이지 요약 (초안)

2026-10-18 · 나비 개발자 대표 도영민 · hondi.net

> **초안 안내**
> 본 문건은 **초안**이며, **예고 없이 변경될 수 있습니다.** 컨소시엄 참여자(개인·법인)가 확정된 후에 **정식 문서를 확정**합니다. 정식 문서가 확정되기 전에는 이 문건의 어떤 내용도 확정된 약속이 아닙니다.

---

| 항목 | 내용 |
|---|---|
| **방향** | 이미 설립된 사무소(개인·법인)가 컨소시엄을 이루어 직능별 **주식회사를 공동 출자**합니다. 나비웹이 법인을 100% 설립하고 주식을 입찰로 모집하던 이전안은 이 방향으로 대체되었습니다 |
| **직능별 제안서** | 법무사, 행정사, 변호사, 세무·회계(통합), 변리사, 감정평가사, 의사, 공인중개사, 약사, 한의사 (10개 문서) |
| **법인의 성격** | 직능별 주식회사(가칭). 해당 직역의 업무를 수행하지 않는 소프트웨어·SaaS 보급 법인 |
| **출자** | 참여 사무소가 주식을 인수합니다. 자본금 총액과 사무소별 인수액은 **미확정** |
| **주식 발행** | 총 발행 예정 주식을 10%씩 나누어 **회차별로 발행**합니다. 1회차는 설립 시, 후속 회차는 유료 이용자 수가 시장 규모의 일정 비율에 이를 때 엽니다(비율 미확정). 1회차 인수자에 대한 추가 보상은 미확정이며 법률·세무 검토 대상입니다 |
| **선지급** | 납입된 출자금(현금)으로 **1년치 추정 로열티를 나비웹에 선지급**하며, 나비웹의 **국산 LLM 서버 구축 비용 중 일부**로 쓰입니다. 회계상 선급 비용이며 등기 자본금은 변하지 않습니다 |
| **이용료·로열티** | 법인이 나비웹에 AI 모델 이용료 또는 로열티를 지급합니다. 산정 기준과 요율은 미확정이며, GPL v3.0 소스에 대한 사용료 부과의 범위는 법률 검토 대상입니다 |
| **이용자 요금** | 전문가와 사무소 직원 **각각 연 99,000원** + 사용량 종량제. 징수 주체와 종량 단가는 미확정 |
| **지배구조** | 주주총회·이사회. 나비 개발팀은 의결권 없는 간사이며 이사·감사가 되지 않는 방안을 검토합니다. 나비웹과의 계약은 주주총회 승인을 받는 방안을 검토합니다 |
| **공정한 경쟁** | 업무 보수·가격은 각 사무소가 독립적으로 정하고, 사무소 간 정보를 교환하지 않으며, 가입은 열려 있습니다. 소개의 대가는 없습니다 |
| **업무 원칙** | AI는 초안과 점검을 맡고 **최종 판단·승인은 자격자**가 합니다. AI 작성과 사람 승인의 이력은 Openhash에 남기고, 직원 계정에는 승인 권한이 없습니다 |
| **홍보** | 주주의 동료 소개는 선택입니다. 주주라는 사실을 밝히고, 단정·수치와 자격 오인 표시를 쓰지 않습니다 |
| **런칭** | 전국 규모. 제주 파일럿은 두지 않습니다. 사전 협의(법률 검토, 직역 단체 협의, 면허 인증 연동)가 끝난 뒤 시기를 확정합니다(미확정) |
| **주요 위험** | 출자금 손실 가능, 선지급 회수 위험, 비상장 주식의 환금성, 지분 희석, 직역법 쟁점, 증권 규제, GPL·비영리 구조와의 정합 |
