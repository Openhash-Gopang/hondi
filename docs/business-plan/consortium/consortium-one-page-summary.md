# 나비 컨소시엄 1페이지 요약 (초안)

2026-10-18 · 나비 개발자 대표 도영민 · hondi.net

> **전체 문서**: 이 문건은 한 페이지 요약입니다. 요약본과 전문가 검토 요청서, 직능별 제안서 10종을 빠짐없이 한 문서로 묶은 [컨소시엄 전체 문서](./consortium-full-document.md)를 함께 보십시오. <!-- navi-full-document-link-v1 -->

> **초안 안내**
> 본 문건은 **초안**이며, **예고 없이 변경될 수 있습니다.** 참여자(개인·법인)가 확정된 후에 **정식 문서를 확정**합니다. 정식 문서가 확정되기 전에는 이 문건의 어떤 내용도 확정된 약속이 아닙니다.

> **구조 개정 (2026-10-18)**
> 이 요약은 '기존 사무소가 공동 출자해 법인을 설립하는 방식'에서 **'나비웹이 직역별 법인을 100% 설립하고, 개시 전에 지분 5%를 해당 직역 전문가에게 균일가 입찰로 매각하는 방식'** 으로 개정되었습니다. 문서 이름의 '컨소시엄'은 해당 직역 전문가들이 같은 법인의 주주로 참여한다는 뜻으로 남겨 두었습니다. <!-- navi-structure-v2 -->

---

| 항목 | 내용 |
|---|---|
| **방향** | 나비웹이 직역별 **주식회사 10개를 100% 설립**하고, 서비스 개시 전에 각 법인 지분 5%를 해당 직역 전문가(개인·법인)에게 매각합니다. 기존 사무소의 공동 출자 방식과 나비웹 무지분 방식은 이 방향으로 대체되었습니다 |
| **설립** | 나비웹(자본금 1억 원)이 법인마다 **1,000만 원**(액면가 100원, 10만 주)을 출자해 10개 법인을 설립합니다 |
| **주식 매각** | 개시 전 **5%(5,000주)** 를 **구글 방식(균일가 입찰)** 으로 매각합니다. 모자라면 추가 5%를 같은 방식으로 매각하며, 나비웹은 90% 이상을 보유합니다 |
| **매수 자격** | **해당 직역 전문가(개인·기관)로 제한**합니다 |
| **매각 대금** | 나비웹이 파는 구주 매출이므로 대금은 나비웹으로 가며, 10개 법인 합계 **최소 5억 원 이상**을 목표로 합니다. **국산 LLM 서버 구축 비용에 전액** 쓰고 사용 내역을 공개합니다 |
| **정부 지원과 개발** | 정부 GPU 지원(최장 9개월)을 확보하고(조건 미확정) 전문 분야별 자체 LLM의 fine-tuning을 시작합니다 |
| **직능별 제안서** | 법무사, 행정사, 변호사, 세무·회계(통합), 변리사, 감정평가사, 의사, 공인중개사, 약사, 한의사 (10개 문서) |
| **법인의 성격** | 직능별 주식회사(가칭). 해당 직역의 업무를 수행하지 않는 **IT SaaS** 보급 법인이며, 이 때문에 직역법상 제한이 없다는 것이 나비웹의 판단입니다(직역 단체 협의와 전문가 검토로 확인) |
| **지배구조** | 나비웹이 **해당 직역 전문가인 주주들 가운데 대표이사와 이사를 선임**하고, 이사진은 그 직역 전문가로 구성해 경영에 참여합니다. 나비웹은 지배 주주입니다 |
| **이용료·로열티** | 나비웹 지분이 **51% 이상인 동안에는 받지 않습니다.** 51% 미만이 된 뒤의 요율은 미확정이며, GPL v3.0 소스에 대한 사용료 부과의 범위는 법률 검토 대상입니다 |
| **특수관계 거래** | 나비웹은 최대 주주이므로 법인과의 거래는 특수관계 거래로 신고합니다 |
| **개시 조건과 환불** | 별도 문서(초안)에서 확정하며, 확정 전에는 입찰을 열지 않습니다 |
| **증권 규제** | 총 매각액이 30억 원 미만이라 증권신고서 면제 구간(소액공모)으로 보고 있습니다(2026-07 개정 보도 기준, 확인 필요) |
| **이용자 요금** | 전문가와 사무소 직원 **각각 연 99,000원** + 사용량 종량제. 징수 주체와 종량 단가는 미확정 |
| **나비웹의 수익 사용** | 서버 구축 비용을 뺀 나비웹의 수익은 **전액 공적 목적**(저소득층 AI 접근, 입법·사법·행정의 AI 전환, 완전 고용·무상 교육·무상 의료·무상 주거 사회를 위한 활동)에 쓰며, **완전 고용을 핵심 목표**로 합니다 |
| **공익성 보호** | 나비웹의 공익 목적을 **나비웹과 법인의 정관에 명시**하고, 변경 요건을 무겁게 하며(번복 불가 조항), 번복 시도 때 주주가 쓸 수 있는 구제 수단(유지청구, 대표소송, 계약상 환매·손해배상)을 정해 둡니다. 소송은 주주의 선택이라 자동으로 제기되지는 않으며 효력은 법률 검토 대상입니다 |
| **나비웹 경영권** | 한시적으로 **창립자 개인이 보유**하고, 시장 점유율이 일정 수준(미확정)에 이르면 공익 이사진을 구성합니다. 이사진 구성 알고리즘(예: 이용자 사용량에 따른 차등 의결권으로 이사진 선출, 이사진이 대표이사 선출)은 미리 구현해 정관에 명문화합니다 |
| **공익 보호 장치** | 공익 보호 종류주식(황금주)과 창립자 주식의 의결권 신탁을 **한국천주교주교회의와 노무현재단을 포함한 복수 수탁자 그룹**에 맡기고, 경영권은 **5년과 메시징 앱 시장 점유율 30% 중 빠른 시점**에 나비웹 사용자들이 선출한 이사진에 넘겨 경영을 맡기고(황금주는 공익 목적 이탈 방지에만 사용), 해산 시 잔여재산은 수탁자 그룹 구성 기관 기부를 포함해 공익 목적에 씁니다. 그룹 구성, 의사결정 방식, 수락 여부, 법적 효력은 미확정입니다. 상세는 별도 문서 「공익성 보호 장치」 |
| **공정한 경쟁** | 업무 보수·가격은 각 사무소가 독립적으로 정하고, 사무소 간 정보를 교환하지 않으며, 입찰 참여는 열려 있습니다. 소개의 대가는 없습니다 |
| **업무 원칙** | AI는 초안과 점검을 맡고 **최종 판단·승인은 자격자**가 합니다. AI 작성과 사람 승인의 이력은 Openhash에 남기고, 직원 계정에는 승인 권한이 없습니다 |
| **홍보** | 주주의 동료 소개는 선택입니다. 주주라는 사실을 밝히고, 단정·수치와 자격 오인 표시를 쓰지 않습니다 |
| **런칭** | 전국 규모. 제주 파일럿은 두지 않습니다. 사전 협의(법률·세무 검토, 직역 단체 협의, 면허 인증 연동)가 끝난 뒤 시기를 확정합니다(미확정) |
| **주요 위험** | 매수 대금 손실 가능, 나비웹이 지배 주주인 구조의 소수 주주 위험, 비상장 주식의 환금성, 개시 전 가격과 증여세, 직역법 쟁점, 증권 규제, GPL·비영리 구조와의 정합 |

| 세무·회계 | 세무대리 오인 광고 금지, 명의대여 금지, 외부감사 독립성 |

| 약사 | 환자 정보 처리, 소프트웨어 의료기기 해당 여부, 약국 개설·의약품 광고 |
| 공인중개사 | 중개보수 한도와 금지 행위, 시장 위축 |
