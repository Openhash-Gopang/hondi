# 나비 컨소시엄 전문가 검토 요청서 (초안)

2026-10-18 · 나비 개발자 대표 도영민 · hondi.net

> **초안 안내**
> 본 문건은 **초안**이며, **예고 없이 변경될 수 있습니다.** 컨소시엄 참여자(개인·법인)가 확정된 후에 **정식 문서를 확정**합니다. 정식 문서가 확정되기 전에는 이 문건의 어떤 내용도 확정된 약속이 아닙니다.

> 이 요청서는 법무·세무·회계 전문가에게 검토를 부탁드리기 위한 질문 목록입니다. 검토 결과가 나오기 전에는 어떤 법인도 설립하거나 주식을 모집하지 않습니다.

---

## 1. 검토를 요청하는 구조

기존 사무소(개인·법인)가 컨소시엄을 이루어 직능별 **주식회사를 공동 출자**합니다. 법인은 나비웹 기반 업무 보조 AI를 해당 직능의 전문가와 직원에게 소프트웨어(SaaS)로 보급해 수입을 올리고, 나비웹에 AI 모델 이용료 또는 로열티를 지급합니다. 설립 시 납입된 출자금으로 **1년치 추정 로열티를 나비웹에 선지급**하며, 이는 나비웹의 국산 LLM 서버 구축 비용 중 일부로 쓰입니다. 나비 개발팀은 공급자이자 간사입니다. 나비웹은 법인의 주식을 보유하지 않고 이용료·로열티만 받으며, 법인은 해당 직역의 개인 전문가와 법인의 출자로 설립되어 독립적으로 운영됩니다.

## 2. 공통 질문

| 번호 | 쟁점 | 요청하는 검토 |
|---|---|---|
| 1 | **증권 규제** | 주식 인수를 권유받는 사람의 수와 방식에 따라 증권신고 의무가 생기는지, 사모로 설계할 수 있는 범위 |
| 2 | **지배 방지** | 1주 1표 원칙 아래 인수 한도, 양도 제한, 가중 결의, 주주 간 계약으로 특정 사무소의 지배를 막을 수 있는지. 구성원당 1표 방식의 구현 가능성 |
| 3 | **이해관계 거래** | 나비웹(공급자)과 법인의 계약에 대한 이사 자기거래 규정, 주주총회 승인, 나비 개발팀 소속자의 이사·감사 배제의 실효성 |
| 4 | **선지급 로열티의 회계** | 선급 비용 인식과 차감 방식, 정산(이월·반환·추가 지급), 서버 구축 지연 시 반환 조건의 법적 구성 |
| 5 | **선지급 로열티의 세무** | 법인세법상 손금 인정과 시가 초과 여부, 특수관계인 거래 해당 여부, 부가가치세 처리 |
| 6 | **GPL v3.0** | 소스 공개 소프트웨어에 대한 로열티·사용료 부과의 가능한 범위(모델 추론·호스팅·지원 서비스 대가), 원 모델(A.X 4.0 등)의 라이선스 조건 |
| 7 | **비영리 구조와의 정합** | 나비웹이 비영리 구조를 표방하면서 로열티와 선지급을 수령하는 것의 법적·세무적 정합 |
| 8 | **공정거래법** | 경쟁 관계의 사무소들이 공동 출자하는 법인의 공동행위 해당 여부, 정보 교환 차단, 가격 독립 원칙, 열린 가입 요건 |
| 9 | **광고·소개** | 주주의 동료 소개의 이해관계 공개 방식, 소개 대가 금지, 표시·광고 규정, 직역별 광고 규제와의 관계 |
| 10 | **개인정보·건강정보** | 이용자 데이터 금고(PDV)에 저장하고 서버에는 저장하지 않는 설계의 법적 평가, 처리 위탁 구조 |
| 11 | **자격자의 출자·겸업** | 각 직역법상 자격자 개인과 법인(세무법인, 특허법인 등)이 주식회사의 주식을 취득할 수 있는지, 신고·제한 |
| 12 | **세법 일반** | 출자금 납입, 배당, 증자 시의 과세 쟁점 |
| 13 | **무지분 공급 구조** | 나비웹이 주식 없이 이용료·로열티만 받는 구조에서의 특수관계인 해당 여부, 이용료·로열티가 독립 당사자 간 가격인지 판단하는 기준, 법인의 독립 운영을 확인하는 요건 |

## 4. 검토 결과의 형식(제안)

- 질문별로 **결론(가능, 불가, 조건부)**, 근거 조문, 위험 수준, 구조 수정안을 구분해 주십시오.
- 확인하지 못한 조문이나 해석이 갈리는 부분은 그렇게 표시해 주십시오.
- 검토 결과는 정식 문서(협약서, 정관, 주주 간 계약)에 반영합니다.
