# 서버 담당자 전달 문서 — REQUIRED_DOCUMENTS_REGISTRY 점검 결과 (2026-10-19)

행정기관 페이지 조사(`docs/gov-agency-research/`)에서 서버 `worker.js` 의 `REQUIRED_DOCUMENTS_REGISTRY`(접수 task별 필수 서류)와 `AGENCY_TO_DEPT_TARGET`(부서 지정)이 법령·공식 안내와 어긋나는 곳을 모은 것이다. **이 문서는 수정 제안이며 서버 코드는 바꾸지 않았다.** 수정 전에 해당 업무의 담당 공무원 또는 법령 원문으로 다시 확인할 것.

## 읽는 법
- **확신도 높음**: 국가법령정보센터의 서식·조문 원문, 또는 법령 DB 본문으로 직접 확인. **중간**: 정부24·법제처 생활법령정보·정부 부처 안내 인용. **낮음**: 보조 출처이거나 일부만 확인.
- 「노트」는 근거 출처와 조회일이 있는 조사 노트(`notes/…`)다. 열린 문제 번호(#)는 `open-issues.md` 의 번호.
- 아래 task 키는 서버 레지스트리 키(`지역접두:task_key`)다.

## D. 관할(접수 권한) 확인이 필요한 것
법령상 수리권자가 시·도지사(제주특별자치도지사)로 읽히는데 SP·서버는 행정시 과가 접수하는 구조다. 위임 근거를 확인해야 한다.
- 대기배출시설 설치신고(#19): 수리권자 시·도지사. 환경관리과 SP가 스스로 「행정시 사무위임을 전제」라고 밝힘.
- 여객자동차운송사업 등록(#25): 시·도지사에게 등록. 
- 도시공원 점용허가(#20): 법 제24조 허가권자에 특별자치도지사 포함, 공원녹지과 SP는 「시청 고유 사무」라고 적음.
- 지방세 이의신청(세무과): 이의신청서 서식 원문은 특별자치도세를 특별자치도지사에게 제출하도록 안내한다(#6). 취득세 신고서는 시행규칙 제9조 ①상 납세지 관할 시장·군수·구청장 제출이고, 제주에서의 실제 접수 창구는 확인하지 못했다.

## E. 수정 순서 제안
1. **근거 표기 오류**: 마을기업(#21) — 사실과 다른 문구가 접수 연동 화면에 그대로 노출된다(페이지에는 정정 안내를 덧붙여 둠).
2. **신청서 누락**(A-1) — 신청서가 접수 서류 점검에서 빠질 수 있다(서버의 완결 판단 로직은 확인하지 못함).
3. **법령상 필수 서류 누락**(A-2의 확신도 높음·중간 항목).
4. **필수 여부·서류명 불일치**(A-3, A-4).
5. 낮은 확신도 항목은 담당 공무원 확인 후 결정.

## 수정 후 점검 방법
- `node tools/extract-gov-tasks.cjs` 로 `assets/gov-agency-tasks.js` 를 다시 만들면 페이지의 「접수 연동 민원」 탭이 바뀐 서류를 따른다.
- `node --test src/tests/gov-agency-page.test.mjs` 가 재생성 결과와 커밋된 파일의 일치를 검사한다.
- 서류를 바꾼 task는 해당 조사 노트와 내용 파일(`assets/gov-agency-content/…`)의 안내문(「서버 접수 목록에는 …없습니다」)도 함께 고쳐야 한다. 이 안내문은 조회일(2026-10-19) 기준 서버 상태를 서술한다.
