# 조사 노트 — 제주시청 복지위생국 기초생활보장과 (3회차)

- 기관 코드: `city-dept:jejusi:SP-CITYDIV-JEJUSI-WELFARE-BASICLIVELIHOOD` · 정본 SP: `prompts/gov-tree/04-city/divisions/SP-CITYDIV-JEJUSI-WELFARE-BASICLIVELIHOOD_v1.2.md`
- 조회일: 2026-10-19 · 내용 파일: `assets/gov-agency-content/jejusi-livelihood.js`
- 방법: SP §2 분장사무 18건(추출 도구) 중 급여 신청을 골라, 서버 레지스트리(`jejusi:basic_livelihood_benefit_application`)의 서류 3종을 법령 서식 원문과 대조.

## 서버 레지스트리와의 대조 — 전부 일치
| 서버 등록 서류 | 법령 서식 |
|---|---|
| 사회보장급여 신청(변경)서 | 사회보장급여 관련 공통서식에 관한 고시 **별지 제1호서식**(개정 2026.5.1.) — 법령정보센터 서식 원문 |
| 소득·재산 신고서 | 고시 **별지 제1호의2서식** — 같은 서식 원문의 첨부서류 표기, 정부24 |
| 금융정보등 제공 동의서(수급권자·부양의무자) | 고시 **별지 제1호의3서식** — 같은 서식 원문, 지자체 게시본(개정 2022.9.5.) |

## 확인한 것
- 신청서 본문: 동 신청서를 접수한 보장기관의 장이 사회보장급여법 제7조·제19조에 따라 조사, 개인정보 제3자 제공 동의, 배우자 동시 신청 시 배우자 서명, 부양의무자 조사 서류(금융정보 등 제공 동의서) 필요할 수 있음, 소득·재산 확인 서류(임대차 계약서, 급여명세서 등) — 법령정보센터 서식 원문
- 시행령 제2조 ①: 신청서에 부양관계·소득·재산상태·건강상태 확인 서류를 첨부해 보장기관의 장에게 제출 — 법령 DB 사이트 본문
- 기초법 시행규칙 서류 목록에 금융정보등(제21조제3항) 제공 동의서 포함 — 법령정보센터 조문 일부
- 서버 레지스트리의 근거(기초법 제21조)는 금융정보 제공 동의서 본문이 인용하는 조문과 일치

## 확인하지 못한 것
- 기초법 제21조·시행규칙 제34조·제35조 현행 본문, 제1호의2·제1호의3서식의 현행 개정일(제1호의3은 2022.9.5. 게시본만 봄)
- 급여별(생계·의료·주거·교육) 서류 차이, 처리 기간, 제주시 접수 창구(시청 과 vs 읍·면·동)
- 서식 본문의 세부 기재 항목(서식 원문의 일부만 읽힘)
