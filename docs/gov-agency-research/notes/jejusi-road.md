## 서버 등록 서류와의 대조
| 서버 등록 | 법령·안내 |
|---|---|
| (없음) | **도로점용허가 신청서** 도로법 시행규칙 별지 제24호서식(개정 2022.11.17.), 근거 도로법 제61조·시행령 제54조 ① — 법령정보센터 서식 원문. 서버에 신청서 자체가 없음(열린 문제 #23) |
| (없음) | 설계도면(전자도면) — 첨부서류 1, 서버에 없음 |
| 점용계획서(필수) | 법령 서식·안내에 없는 이름. 안내는 「사업계획서」 — 불일치 |
| 위치도(필수) | 국민마당 안내(일반 점용의 구비서류)에 있음. 서식 본문에는 없음 |
| 시공계획서(필수) | 법령·안내에서 확인되지 않음. 서식은 공사의 방법·시기를 신청서에 적도록 함 |

## 확인한 것
- 도로법 제61조 ①: 도로점용은 도로관리청의 허가, 기간 연장·사항 변경도 같음 / 제62조: 안전관리, 굴착 등 공사 후 준공확인 — 국가법령정보센터 조문
- 신청서 유의사항: 굴착 점용은 신청 전 사업계획서를 도로관리청에 제출해 도로관리심의회 조정을 받음(시행령 제56조 ①), 점용기간 연장은 허가기간 끝나기 전 연장허가 — 서식 원문
- 허가수수료 1,000원 또는 조례 금액, 점용료 산정(시행령 별표 3) — 국토교통부 안내

## 확인하지 못한 것
제주 도로의 도로관리청, 제주시 조례 수수료·점용료, 현행 조문, 서버 「점용계획서」·「시공계획서」의 실체.
