## 서버 등록 서류와의 대조
| 서버 등록 | 법령·안내 |
|---|---|
| 피해사실확인서 | 법령상 서류는 「자연재난 피해신고서」(별지 제1호서식), 재난 종료일부터 10일 이내(제9조 ②) — 같은 서류인지 미확인(열린 문제 #30) |
| 재산피해 증빙 | 같은 이름의 서류를 확인하지 못함. 피해 확인은 신고 내용 기반 사실 확인 후 지급(제9조 ⑨) |
| (없음) | 주민등록표 등본, 소득금액증명, 가족관계증명서는 행정정보 공동이용으로 확인(제9조 ⑤), 동의하지 않으면 직접 첨부 |

## 확인한 것
- 신고 상대방은 시장·군수·구청장, 부득이한 사유 시 사유 종료일부터 10일, 기간 연장 가능
- 재난안전법 목차: 제58조 재난피해 신고 및 조사, 제66조 재난지역에 대한 국고보조 등의 지원(제목만)

## 불일치·주의
- 이 규정은 자연재난용이다. 사회재난은 별도 규정이며, 서버 task가 구분하는지 알 수 없다.

## 확인하지 못한 것
재난안전법 제58조·제66조 본문, 별지 제1호서식 원문, 지원 금액(별표 3, 고시), 사회재난 규정의 서류, 제주시의 실제 접수 창구, 규정의 최신 개정.
