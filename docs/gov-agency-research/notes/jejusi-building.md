- 방법: 서버 레지스트리 `jejusi:building_permit`(설계도서, 구조계산서, 토지이용계획확인서)을 건축법 시행규칙 조문·서식 원문과 대조.

## 확인한 것 (국가법령정보센터)
| 항목 | 결과 |
|---|---|
| 시행규칙 제6조 ① (시행 2026.2.27., 국토교통부령 제1567호) | 허가 신청은 **별지 제1호의4서식** 「건축·대수선·용도변경(변경)허가 신청서」에 사전결정서, 별표 2의 설계도서(사전결정 시 건축계획서·배치도 제외, 표준설계도서 시 건축계획서·배치도만), 법 제11조제5항 관련 서류, 결합건축협정서 등을 첨부해 허가권자에게 제출 |
| 시행규칙 제12조 ① | 신고는 **별지 제6호서식**에 첨부해 특별자치시장·특별자치도지사 또는 시장·군수·구청장에게 제출. 첨부에 대지의 범위·소유 또는 사용 권리 증명 서류 |
| 별표 2 (개정 2018.11.29.) | 건축계획서, 배치도, 평면도, 입면도, 단면도, 구조도, 실내마감도, 소방설비도 |
| 별지 제6호서식 | 세움터(eais.go.kr)에서도 신청 가능, 신고 대상 예(연면적 100㎡ 이하 건축물의 건축 등), 처리기간 5일·수수료 별표 4 — 구 개정본(2013·2018) 안내 |

## 불일치
- 서버 필수 서류 중 **구조계산서·토지이용계획확인서**는 제6조 ①의 읽은 본문에서 확인되지 않음(열린 문제 #11). 건축법 구조안전 확인 서류 규정과 행정정보 공동이용 규정을 전문으로 대조해야 한다.
- 제가 처음 추정한 서식 번호(별지 제1호의2)는 틀렸고 현행은 제1호의4다. 서식 번호는 추정하지 않고 조문 원문으로 확인한다.

## 확인하지 못한 것
허가·신고 대상 구분(제11조·제14조), 수수료(별표 4)·처리기간 현행 값, 별지 제1호의4서식 본문, 사용승인(제주시 레지스트리 미등록, 열린 문제 #2), 제주시 건축과의 접수 범위.
