# K-Estate 가치평가 방법론 체계 (2026-09-28)

이 문서는 통상의 부동산 가치평가 3방식과, 그 위에 한국 특성 요소를
체계적으로 얹은 참고 자료다. `hondi-staged-valuation.js`(SP-24a) 다음
버전을 설계할 때 체크리스트로 쓰기 위해 정리했다 — 이 문서 자체는
아무것도 구현하지 않는다(순수 참고 문서, 코드 변경 없음).

## 1. 통상의 3방식 (국제 표준 + 한국 감정평가 실무)

| 방식 | 원리 | 적합 대상 | 한계 |
|---|---|---|---|
| **원가법(Cost Approach)** | 재조달원가 − 감가수정 | 신축 건물, 시장성 낮은 특수 목적 부동산(공장·학교 등) | 토지는 원가 개념 적용 곤란 → 토지는 보통 공시지가기준법 병용 |
| **거래사례비교법(Sales Comparison Approach)** | 유사 거래사례를 사정보정·시점수정·가치형성요인 비교로 조정 | 아파트 등 거래 빈번한 부동산 — 가장 널리 쓰임 | 비교 가능한 사례 부족 시 신뢰도 하락 |
| **수익환원법(Income Capitalization Approach)** | 순영업소득(NOI) ÷ 환원율(cap rate), 또는 할인현금흐름(DCF) | 임대용 상가·오피스·물류센터 등 수익형 부동산 | 임대료·공실률·환원율 추정의 주관성 |

한국은 「감정평가에 관한 규칙」이 부동산 종류별로 이 세 방식 중
**주방식**을 법정화해 둔다(토지는 공시지가기준법 우선, 건물은 원가법,
임대용 부동산은 수익환원법 등).

**현재 hondi 구현 범위**: SP-24a·SP-24_kestate는 거래사례비교법 +
공시지가기준법 계열만 구현했다. 수익환원법(임대 수익형 부동산)과
원가법(신축·특수 부동산)은 아직 다루지 않는다 — 4절 갭 표 참조.

## 2. 감정평가법의 조정 순서 (SP-24a가 따르는 골격)

- 거래사례비교법: **사정보정 → 시점수정 → 가치형성요인 비교**(지역요인 → 개별요인)
- 공시지가기준법: **시점수정 → 지역요인 비교 → 개별요인 비교 → 그 밖의 요인 보정**

hondi 체계는 이를 **국가(시점수정) / 지역(지역요인) / 개별(개별요인+권리)**
3단계로 재구성했다(`hondi-staged-valuation.js`). 아래 한국 특성 요소들은
이 세 단계 중 어디에 속하는지, 그리고 이미 합의된 핵심 원칙 —
"정성 요인은 σ(불확실성)만 확대, 관측된 가격 수준비만 중앙값 이동" —
과 어떻게 맞물리는지로 분류했다.

## 3. 한국 특성 요소 체계

### 3-A. 권리분석 (개별 단계)

| 요소 | 내용 | 현재 처리 방식 / 상태 |
|---|---|---|
| 근저당권 | 채권최고액, 설정 순위 | 제3자 근저당 → **담보가치에서만 차감**, 자산 공정가치는 불변 — 구현됨 |
| 가압류·가처분 | 처분금지 효력 | 매각 자체를 저해 → 거부조건 후보 — **미구현** |
| 전세권·지상권·지역권 | 용익물권 | 대항력 있으면 인수부담 분류 필요 — 유형 세분 **미구현** |
| 유치권 | 공사대금 등 | 존재 시 처분가치 급락 → 별도 거부조건 필요 — **미구현** |
| 말소기준권리 판단 | 경매 시 어떤 권리가 소멸/인수되는지(보통 최선순위 근저당·가압류·경매개시결정 중 가장 빠른 것 기준) | 지금은 "인수부담 vs 제3자 근저당" 이분법뿐 — 정교한 말소기준권리 판단 로직 **미구현**(현재는 "등기부 미확인 시 전체 거부"로만 방어) |

### 3-B. 임차인 보호법 적용 여부 (개별 단계)

| 요소 | 내용 | 현재 처리 방식 / 상태 |
|---|---|---|
| 주택임대차보호법 | 대항력(전입신고+점유), 우선변제권(확정일자), 소액보증금 최우선변제 | 대항력 있는 선순위 임차보증금 → **인수부담으로 공정가치 차감 — 구현됨** |
| 상가건물임대차보호법 | 환산보증금(보증금+월세×100) 기준 이하만 전면 적용, 초과 시 일부 조항만 적용 | **미구현**. 환산보증금 기준액은 주기적으로 개정되는 값이라 코드에 하드코딩하지 말고, SP가 매번 웹 검색으로 현재 기준을 확인하도록 설계할 것(SP-24a의 "출처+조회일" 원칙과 정확히 맞는 사례) |
| 계약갱신청구권 | 임차인의 갱신요구권 행사 여부·잔여 행사 가능 횟수 | 매수인이 인수하는 부담 성격 — **미구현** |
| 권리금 보호(상가) | 임차인의 권리금 회수 기회 보호 | 상가 가치평가 시 실질적 매도 제약 요인 — **미구현** |

### 3-C. 임차인 존재 여부 (개별 단계)

공실 vs 임대 중인지 자체가 매수인 관점의 가치를 바꾼다(즉시 사용
가능 vs 명도소송 리스크). 보증금·월세·계약기간·갱신 여부까지 세트로
확인해야 3-B의 대항력 판단이 가능하다. **현재 SP-24a는 "임차인
존재"를 독립 항목으로 묻지 않고 "인수부담 있는지"만 묻는데, 순서상
임차인 존재 확인이 선행돼야 한다 — 질문 순서 개선 필요.**

### 3-D. 지역요인 — 정성 위험(σ만 확대 원칙 적용 대상)

| 요소 | 현재 SP-24a 반영 여부 | 비고 |
|---|---|---|
| 교통(간선도로·고속도로 IC 접근성) | **미반영** | `infra_downgrade`가 "축소"만 다루고 기존 접근성 수준 자체는 안 다룸 |
| 차량 진입 가능 여부(맹지 여부, 건축법상 도로 폭 2m 접합 요건 등) | **미반영** | 성격상 지역요인이 아니라 **개별요인**(그 필지 고유 문제)이다. 맹지면 건축 자체가 제한되므로 σ가 아니라 별도 defect나, 심하면 거부조건 후보로 다뤄야 함 |
| 인근 상권 | **미반영** | |
| 대중교통(역세권 여부) | **미반영** | 역세권은 시장 반영이 가장 빠른 요인 중 하나라, 정성 위험 σ보다는 "비교사례를 같은 역세권 등급으로 맞추는" 접근이 더 정확할 수 있음(향후 설계 시 검토) |
| 학교/학군 | `school_consolidation`(통폐합 리스크)만 반영됨 | "학군 자체의 선호도"는 다른 성격(상방 요인일 수도 있어 "위험" σ 모델과 안 맞음 — 별도 검토 필요) |
| 치안 수준 | **미반영** | 경찰청 범죄 통계 등 신뢰할 만한 공개 출처 확보 가능성 자체를 먼저 조사해야 함 |
| 인구 변동 | `population_decline` 반영됨(행안부 주민등록 인구통계) | |
| 주요 산업 | **미반영** | 지역 고용 기반(대기업 사업장 등) 붕괴는 인구감소의 선행지표 성격 — `population_decline`과 중복 가능성 있음, 별도 요인으로 둘지 검토 필요 |

## 4. 갭 요약 및 우선순위 제언

1. **말소기준권리 판단 로직** — 권리분석 중 가장 중요한 갭. 지금은
   "선순위 권리 불명이면 전체 거부"뿐이라 안전하지만, 실제 등기부가
   확보돼도 정교한 처리를 못한다.
2. **맹지·도로접합 여부**를 개별요인 defect로 추가 — 건축 가능 여부를
   좌우하므로 다른 defect보다 가중치가 커야 한다.
3. **상가건물임대차보호법 환산보증금**은 숫자를 코드에 박지 말고 SP가
   매번 최신 기준을 웹 검색하도록 설계.
4. 교통·상권·치안·대중교통은 지역요인 σ 확장 목록 후보이지만, 각각
   신뢰할 만한 공개 출처를 먼저 확인해야 "지어내지 않는다" 원칙을
   지킬 수 있다 — SP-24a `[한계]` 섹션과 같은 성격의 선행 조사 과제.
5. **수익환원법(수익형 부동산)·원가법(신축/특수 부동산)**은 이 체계
   자체에 아직 없다 — 거래사례비교법 계열만으로 커버 안 되는 부동산
   유형(상가·오피스 임대, 신축)을 다루려면 별도 SP 또는 SP-24a의
   모드 분기로 설계해야 한다(이번 문서 범위 밖, 향후 과제로만 기록).

## 5. 이 문서의 성격

이 문서는 설계 참고 자료이며, 여기 나열된 "미반영" 항목을 실제로
구현하는 작업은 각각 별도 커밋으로 진행해야 한다(이 문서 자체는 코드를
바꾸지 않는다). 각 항목을 구현할 때도 K-Estate 핵심 원칙 — AI는
계산하지 않는다, 출처·조회일 없는 값은 버린다, 정성 위험은 σ만 키운다,
권리 차감은 인수부담/제3자 근저당 두 갈래로 분리한다 — 를 그대로
따라야 한다.
