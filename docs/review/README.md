# 직역 전문가 검수 패키지 (계획 W4)

- 작성일: 2026-10-21 · 상태: **초안(법률 검토 전)**. `【 】`는 확정 전 빈칸, `[검토]`는 법률 검토 필수 쟁점.
- 목적: 11개 전문가용 AI(변리사, 공인중개사, 세무사, 공인회계사, 감정평가사, 의사, 한의사, 약사, 법무사, 행정사, 변호사)의 **서류 목록·판단 경계·용어**를 해당 직역 전문가가 확인한다.
- 구성: 이 안내서 + `sheets/<직역>-검수시트.md` 11종(SP에서 자동 생성) + `review-log.md`(검수 이력).
- 시트 갱신: SP를 고치면 `python3 scripts/gen-review-packages.py` 로 시트를 다시 만든다(테스트가 동기화를 검사한다). **이미 받은 답변이 있는 시트는 덮어쓰지 말고** 새 날짜 사본으로 보낸다.

## 1. 원칙

1. **검수는 의견이다.** 검수자는 서비스 결과물이나 이용자의 업무에 책임을 지지 않는다(책임 범위는 트랙별 문서에 명시).
2. **검수 대상은 서류 목록, 판단 경계, 용어, SP가 '확인 필요'로 남긴 항목**이다. 법령 원문 대조(W3)는 검수자에게 요구하지 않는다.
3. **모르면 "모름"으로 답한다.** 지어낸 답이 가장 해롭다. 근거 없는 정정은 반영하지 않는다.
4. **이해관계를 공개한다.** 검수자 명단, 트랙, 이해관계, 일자는 검수 이력에 남기고 공개한다.
5. **의뢰인·상담자 정보를 받지 않는다.** 검수에는 실제 사건 자료가 필요 없다. 시트에 실제 개인정보를 적지 않도록 안내한다.
6. 검수 완료 표기는 **트랙과 일자를 함께** 적는다. 검수 이력이 없는 직역은 계속 "검수 전 초안"이다.

## 2. 세 트랙

| 구분 | 트랙 A. 입찰 예정 전문가 | 트랙 B. 자문 계약 전문가 | 트랙 C. 직역 단체 협조 |
|---|---|---|---|
| 역할 | 실무 의견 수렴 | **판단 경계·서류 목록 최종 확정에 쓰는 검수** | 단체 차원 의견·검수자 추천 |
| 보수 | 없음 전제(이해관계 공개) | 【보수·산정 기준】 | 없음(요청 공문) |
| 이해관계 | **있음**(할인 매수 + 검수) | 보수 관계(독립성 조항으로 관리) | 단체의 입장(수락 여부 미확인) |
| 기록상 효력 | **의견 수렴**으로 기록 | 검수로 기록 | 협조로 기록 |
| 문서 | 시트 + 이해관계 공개 | 자문 계약서(§5) + 시트 | 요청 공문(§6) + 시트 |

교차 확인 규칙: **같은 직역에서 트랙 A의 의견만으로는 "검수 완료"로 표기하지 않는다.** 트랙 B 또는 C의 검수를 1건 이상 반영한 뒤 표기한다. [검토: 이 규칙이 이해관계 관리로 충분한지]

## 3. 진행 순서

1. **시범:** 변리사, 공인중개사 (법령 근거가 상대적으로 양호) → 2. 세무사, 공인회계사, 감정평가사, 의사, 한의사, 약사 → 3. 법무사, 행정사(분리 후 신규 SP) → 4. 변호사(법률 검토 회신 후).
2. 직역마다: 검수자 섭외(트랙 A·B·C 동시) → 시트 송부 → 회수 → 반영(SP 수정, 시트·페이지 재생성) → 검수 이력 기록 → 페이지 표기.
3. 변호사·약사는 법령 원문 근거가 약하므로 검수 전에 W3(원문 확인)을 우선한다.

## 4. 검수자에게 보내는 안내문 (초안)

> 안녕하세요. 【법인/나비웹】입니다. 【직역】 전문가용 AI의 초안 단계 내용을 확인해 주실 분을 찾고 있습니다.
> 첨부한 시트에 서류 목록(적정/수정/삭제 판정), 빠진 서류, AI가 "확인 필요"로 표시한 항목, AI의 금지 행위와 판단 경계에 대한 의견을 적어 주시면 됩니다. 소요 시간은 대략 【】시간입니다.
> 법령 전문을 대조하실 필요는 없으며, 모르는 항목은 "모름"으로 두셔도 됩니다. 실제 의뢰인 정보는 적지 말아 주세요.
> 의견은 서비스 개선에 쓰이며 검수 이력에 검수 트랙, 일자, (동의하시면) 성명이 공개됩니다. 이 검수는 결과물에 대한 책임을 지시는 것이 아닙니다.
> 서비스가 직역 법인의 5% 주식 입찰 구조와 연결되어 있으므로, 시트 0번의 이해관계 공개란을 꼭 작성해 주세요.

## 5. 트랙 B — 자문 계약서 핵심 조항 (초안, 법률 검토 전 [검토])

|---|---|
| 당사자·목적 | 【직역 법인】과 검수자. 【직역】 전문가용 AI의 서류 목록·판단 경계·용어에 대한 자문 |
| 범위 | 지정한 시트에 대한 의견 제시. 법령 전문 대조·서비스 운영 책임·이용자 상담은 범위 밖 |

## 6. 트랙 C — 직역 단체 협조 요청 공문 (초안)

> 제목: 【직역】 업무 보조 AI 서비스 초안의 검수 협조 요청
> 수신: 【단체명】 【담당 부서/위원회】
> 1. 【법인/나비웹】은 【직역】의 업무를 보조하는 AI 서비스를 준비하고 있습니다. 이 서비스는 서류 초안 작성을 돕는 도구이며, 서명·제출·대리는 하지 않고 모든 결과는 전문가 확인 전 초안입니다.
> 2. 초안의 서류 목록과 판단 경계에 대해 귀 단체의 의견 또는 검수자 추천을 부탁드립니다. 검토 범위와 양식은 첨부 시트와 같습니다(법령 전문 대조는 요청하지 않습니다).
> 3. 의견 회신 기한은 【】입니다. 수락 여부와 무관하게 서비스는 검수 전 초안임을 화면에 표기합니다.
> 4. 서비스 구조(직역 법인 5% 주식 입찰 등)에 대한 설명 자료를 별도로 드릴 수 있습니다.
> 첨부: 검수 시트, 서비스 개요, 【이해관계 공개 문서】

## 7. 검수 반영과 화면 표기

- 반영 단위: 시트의 판정 → SP 수정(서류명·설명·판단 경계) → `gen-assistant-sp.py` 재생성 → `gen-review-packages.py` 재생성 → 테스트 → 페이지 반영.
- 표기 문구: **"검수 완료 (자문 계약 1인 / 직역 단체 1곳, 2026-11-05)"** 처럼 트랙별 인원과 일자를 적는다. 트랙 A만 있으면 **"입찰 예정 전문가 의견 반영(검수 완료 아님)"**.
- 검수 시점 이후 SP가 크게 바뀌면 표기를 내린다(기준: 서류 목록·판단 경계 변경).
- 개시 조건(계획 W6): 해당 직역의 W3 1차 완료 + **트랙 B 또는 C 검수 1건 이상 반영**.

## 8. 검수 이력

`review-log.md` 에 기록한다(직역, 트랙, 검수자 표기, 이해관계, 일자, 반영 요약, SP 버전).
