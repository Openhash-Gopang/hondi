## 3. 다음 담당자가 반드시 알아야 할 것

**secret 저장소가 3개로 분리돼 있습니다** — 헷갈리면 오늘처럼 몇 시간 낭비합니다:

| 저장소 | 확인 명령 | 예시 |
|---|---|---|
| GitHub Actions secrets | `gh secret list --repo Openhash-Gopang/hondi` | `HONDI_ADMIN_*`, `L1_SSH_*`, `CLOUDFLARE_*` |
| Cloudflare Worker secrets | `npx wrangler secret list` | `L1_ADMIN_EMAIL`, `DEEPSEEK_API_KEY`, ... |
| hanlim 서버 자체 계정 | `sqlite3 pb/hanlim/data.db "SELECT email FROM _admins;"` / `"...FROM prompt_admins;"` | `tensor.city@gmail.com` 등 |

`_admins`(PocketBase 내장) 계정 비밀번호를 바꾸면 **그 계정을 참조하는
Worker secret(`L1_ADMIN_*`)도 같이 갱신**해야 합니다 — 대시보드
로그인만 생각하고 바꾸면 Worker↔L1 내부 인증이 깨집니다(오늘 실제로
겪음).

CLI로 secret 값을 넣을 때 **파이프(`|`)로 넘기면 개행이 붙습니다** —
`--body` 인자 또는 `[System.IO.File]::WriteAllText` + 파일 리다이렉션을
쓰세요. 이 규칙은 2026-07-21에 한 번, 오늘 또 재발했습니다 — 세 번째는
없어야 합니다.
