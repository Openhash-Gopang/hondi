# 세션 기록 — 전문가용 보조 AI SP 이분화와 「작성 문서 목록」 개편 (2026-10-17)

> 주관: 주피터(AI City Inc. 수석 설계자) · 작업: Claude 세션 · 반영 PR: #665(`feature/expert-assistant-sp-all`), #666(`feature/expert-assistant-sp-all3`)

## 1. 지시와 원칙

- 전문가 페르소나 페이지의 「작성 문서 목록」을 갱신한다.
- 직역마다 SP를 둘로 나눈다: **전문가용 `SP_<id>-assistant`**(서류 작성·전문 지식 상담, 인증된 전문가 대상)와 **일반인용 `SP_<id>`**(보편적 상담, 변경 없음).
- AI는 초안을 쓰고 **전문가가 서명·발급**한다. 전문가 판단은 지시한 값만 확정으로 쓰고 나머지는 `[<직역> 기재: …]`, AI 제안은 `[AI 후보 — <직역> 확인]`, 점검은 `[기록 점검]`으로 구분한다. **서식 번호·조문은 원문을 읽은 것만 적고, 지어내지 않는다.**

## 3. 점검에서 나온 결함과 조치

1. **비의료 직역 12개 SP에 의료 문구 혼입**("환자", "의사의 지시", "Navi K-Health", "보건복지부") — 직역별 치환(의뢰인·의뢰인의 요청)과 소관 부처 지정으로 정정, 재생성.
2. **조사 오류**("정확성을(를)", "서명·교부은(는)") — `fix_josa()` 추가, 전 SP 재생성.
3. **세부 분야 서류 제목이 부모와 중복**(계약서 검토표, 합의서 초안, 마취 동의서) — 분야명을 넣어 구분.
4. **치과의사 표기가 비치과 SP에 남음** — 치과 직역 외에는 "의사".
5. **테스트 B-02 실패** — 임시 디렉터리에 `data/` 가 없어 생성 블록이 달랐음 → 테스트가 데이터 디렉터리를 복사하도록 수정.

## 4. 전달 방식에서 얻은 교훈

- 이 Claude 세션은 push 할 수 없다. 전달은 **압축 파일 1개 + PowerShell 스크립트 1개**이며 스크립트는 전문을 본문에 그대로 붙인다(“실행 한 줄”만 보내지 않는다).
- 스크립트는 zip 존재·main 브랜치·작업트리 깨끗함·브랜치 부재를 확인하고, 압축 해제 후 **파일별 허용 blob SHA** 게이트(`_allowed.txt`)로 main 쪽 변경과 충돌하지 않는지 본 뒤 `pull → 브랜치 → 복사 → 테스트 → 파일별 add → commit → push → PR 생성 → merge` 순으로 진행한다.
- **`git rev-parse origin/main:<새 경로>`는 경로가 없으면 fatal** → 없을 수 있는 경로는 `git ls-tree origin/main -- <path>`로 확인하고 `$ErrorActionPreference = "Continue"`로 둔다(PR #665 직전 오류 사례).
- 오래된 작업본의 파일로 덮어쓰지 않는다. main이 더 새로우면 제자리 삽입(앵커 기준)으로 고친다.

## 5. 알려진 한계

- **접근 통제 없음(미결)**: `/ai/chat`은 Origin만 확인하고 SP는 공개 파일이라, SP 키만 바꾸면 전문가용 SP를 누구나 호출할 수 있다. 면허 인증 후 전문가 세션을 발급하고 서버가 전문가용 SP를 막는 작업이 필요하다(인증 방식 결정 선행).
- 서류 목록은 법정 서식과 실무 사례가 섞여 있고, 서식 번호·기재사항·기한은 원문을 읽은 것만 확정이다. 법령 원문을 읽지 못한 직역이 많다.
- 비의료 직역 SP는 의료용 골격에서 만들어 "수행·측정 사실", "수치·단위", 조리사의 "의뢰인" 등 어색한 표현이 남을 수 있다 — 직역 전문가 검수 필요.
- 일반인용 SP에 L2·L3 분기 문구가 남아 있다.
- 세부 분야 SP는 부모 전체의 복사본이다(부모 수정 시 `gen-assistant-child-sp.py --all` 재생성). 회계사 세부 분야 페이지는 19탭·150건으로 탐색성이 떨어진다.

2. 법령 원문 확인 후 서식 확정 — 우선: 정신건강복지법 시행규칙 입원 서식, 모자보건법 시행규칙 별지 제1호, 산업안전보건법 시행규칙 건강진단, 장애인복지법 시행규칙 장애진단서, 변호사법·민사소송법·형사소송법.
