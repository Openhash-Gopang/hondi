## 갱신 규칙

1. 직역을 하나 끝낼 때마다 해당 행의 "조사 상태"를 "완료(확인 수준)"로 바꾸고, 근거 자료를 `docs/research/<직역>_서류_조사_<날짜>.md`에 남긴다.
2. 확인하지 못한 서류·서식 번호는 지어내지 않고 "미확인"으로 적는다.
3. 계열(변호사·의사 등)은 상위 직역에 공통 서류를 두고 세부 분야에는 고유 서류만 추가한다.
4. **직역마다 SP를 둘로 나눈다(2026-10-17 지시).** 일반인용 `SP_<id>`는 신원 확인 없이 호출하는 보편적 상담, 전문가용 `SP_<id>-assistant`는 인증된 전문가의 서류 작성·전문 지식 상담이다. 페이지(생성기 `sp_key`)는 전문가용을 우선한다. 시범: 의사.
