# 의료·보건 3묶음 서류 조사 (2026-10-17)

대상: 전문간호사, 영양사, 조산사, 위생사, 보건교육사, 언어재활사 (전문가용 SP `SP_<id>-assistant` 신설).

| 직역 | 근거 | 확인 수준 |
|---|---|---|
| 전문간호사 | 전문간호사 자격인정 등에 관한 규칙(현행 2025.6.21., 보건복지부령 제1118호; 근거 법령이 의료법→간호법) | 원문 확인(요약 출처): 자격증 별지 제6호, 수료증 별지 제4호, 자격증 발급·갱신·재발급은 간호법 시행규칙의 간호사 면허증 규정 준용(제13조). 간호법 시행규칙 준용 조문, 업무 범위는 미확인 |
| 영양사 | 국민영양관리법 시행규칙(시행 2025.9.30., 제1127호), 식품위생법 시행규칙 | 시행일만 확인, 본문 읽지 못함 — 서식 번호 전부 미확인 |
| 조산사 | 의료법 시행규칙 | 요약 출처: 출생증명서 별지 제7호·사산 또는 사태증명서 별지 제8호(제11조), 수습의료기관 별지 제1호(제3조), 면허증 제2호·등록대장 제3호·정정 제4호·재발급 제5호(제4~6조). 조산기록부·보존기간·조산소 개설 미확인 |
| 위생사 | 공중위생관리법 시행규칙(현행 2026.7.14., 제1186호) 제11조의2~제12조의2 | 원문 확인: 별지 제10호의2(신청서)·제10호의3(면허증)·제10호의4(재발급), 재부여는 원문 표기가 별지 제10호의4호서식(번호 확인 필요), 수수료 재발급·재부여 2천원·증명 500원, 보수교육 조문 없음. 업무·소독 서식 미확인 |
| 보건교육사 | 국민건강증진법 시행규칙 제7조의3 | 원문 확인(최종 개정 2022.3.18., 제872호): 별지 제1호의7(발급신청서)·제2호(재발급)·제3호(발급대장)·제4호(자격증), 사진·경력·이수증명 첨부, 수수료 1만원. 업무 서식 미확인 |
| 언어재활사 | 장애인복지법 시행규칙(시행 2026.7.1., 제1149호) | 시행일만 확인, 본문 읽지 못함 — 서식 번호 전부 미확인 |

## 설계 메모
- 법정 서식이 확인되지 않은 영양사·언어재활사의 서류 목록은 일반 업무 서류이며, 서식 번호는 만들지 않는다.
- 조산사의 출생증명서는 분만에 관여한 조산사만 발급할 수 있으므로, 관여 여부를 확인하는 금지 규칙을 추가했다.
- 전문간호사는 처방권이 없으므로 의사의 지시 범위 안에서만 기록하고, 지시와 다르면 `[지시 확인 필요]`로 표시한다.
- 이 묶음은 2묶음 PR이 병합된 뒤에 적용한다(sp-catalog 등 공유 파일을 2묶음 위에 쌓음).
