# 회계사 9개·변리사 10개 세부 분야 서류 조사 (2026-10-17)

방식: 의사 23개와 같다. 부모 전문가용 SP(`SP_accountant-assistant` v1.1, `SP_patent-attorney-assistant` v1.2) 전체 위에 분야 절(§0-4)과 분야 특화 서류 1절을 덧붙인 독립 SP를 `scripts/gen-assistant-child-sp.py`로 만든다. 회계사 자식 페이지는 부모 18절 + 특화 1절(19탭, 149~150건), 변리사 자식 페이지는 부모 7절 + 특화 1절(8탭, 36건)이다.

## 확인 범위
- 부모 SP가 근거로 든 변리사법 제2조, 공인회계사법 제2조는 부모 조사 결과를 그대로 따른다.
- 이번에 새로 원문을 확인한 법정 서식은 없다. 특화 서류는 모두 실무 문서이며 서식 번호·기한·수수료는 만들지 않았다(전부 "조회 후 확인").
- 외부감사법, 자본시장법, 채무자회생법, 공익법인 관련 규정, PCT·마드리드 규정은 법령명만 적고 조문 번호는 적지 않았다.

## 설계 메모
- 회계사: 감사 의견, 평가 결과, 미비점 분류, 기준서 적용 결론, 상장 가능 여부, 변제 비율, 부정 여부는 AI가 정하지 않는다. 분식·증빙 소급·허위 평가 요청은 거절한다.
- 변리사: 청구범위의 권리 범위, 신규성·진보성, 상표 유사, 침해·무효 판단은 AI가 정하지 않는다. 기한 도과 임박은 서류보다 먼저 변리사 확인으로 안내한다.
- 이 묶음은 6묶음 PR 병합 후 적용한다.
