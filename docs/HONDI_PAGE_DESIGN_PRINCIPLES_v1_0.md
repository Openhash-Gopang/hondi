# 혼디 페이지 디자인 원칙 v1.0

> 2026-09-23 — GDC 탭 리디자인 작업(원자로 제어 패널 스타일 시안, claude.ai 아티팩트로 먼저 검토)에서 확정한 원칙을 문서화. 향후 다른 탭·페이지에도 이 원칙을 적용할 때 참조한다.

## 배경

기존 대시보드 홈/GDC 탭은 카드 3개짜리 SaaS 템플릿 톤(둥근 모서리, 같은 회색 그림자, 흰 배경 카드)이었다. "밀도 높고 압축적이고 전문적인" 화면이 필요하다는 요구에 따라, 원자로 제어실·ICU 환자 모니터·관제센터(SOC) 등 실물 계기판 UI를 조사해 그 원형을 혼디에 맞게 번역했다.

## 조사 결과 — 세 도메인의 공통점

- 색은 정보로만 쓰고 장식으로 쓰지 않는다 (거의 무채색 바탕 + 상태 의미가 있는 색 1~3개)
- 숫자는 전부 고정폭(모노스페이스), 소수점 자리 고정 — 읽을 때마다 자릿수를 다시 세지 않아도 됨
- 상태는 색과 모양을 함께 쓴다 — 색 하나에만 의존하지 않음(색맹·저채도 화면 대응)
- 각진 모듈 그리드, 헤어라인(1px) 경계선 — 카드 그림자·그라디언트·둥근 모서리 없음
- 라벨은 작고 기능적 — "이 숫자가 뭔지"만 설명, 장식용 헤드라인 없음
- 정보 밀도가 높다 — 여백보다 격자와 정렬로 구획을 나눔

## 혼디 적용 — 토큰

### 색 (다크 시안 / 라이트 시안 둘 다 확정)

| 역할 | 다크 | 라이트 |
|---|---|---|
| 배경 | `#0A0D10` | `#EEF1F3` |
| 패널 | `#12161B` | `#FFFFFF` |
| 경계선 | `#232B33` | `#D8DEE4` |
| 본문 텍스트 | `#C7D0D9` | `#1A1F24` |
| 보조 텍스트/라벨 | `#5B6773` | `#6B7480` |
| 정상/충전(초록) | `#3ECF8E` | `#1E9E6C` |
| 주의/사용/경보(황) | `#E0A845` | `#B4790A` |
| 활성/선택(파랑, 딱 한 곳에만) | `#4FA8E8` | `#2567C9` |

라이트/다크 중 하나를 고정하지 않고 컨텍스트에 맞게 고른다 — 어느 쪽이든 위 대응 표를 그대로 맞바꾸면 된다.

### 타이포그래피

- **숫자·데이터**(잔액, 금액, 시각, 표 안의 모든 수치): **IBM Plex Mono** — 반드시 고정폭. 이게 제어반 성격을 만드는 핵심 장치이므로 절대 가변폭 폰트로 바꾸지 않는다.
- **라벨·본문**: 기본은 **Pretendard**(-apple-system/Apple SD Gothic Neo/Malgun Gothic 순서로 폴백). Google Fonts에 없어 웹폰트로 직접 못 불러오는 환경(예: 이번 claude.ai 아티팩트)에서는 시스템 폰트로 자연 대체되도록 폴백 스택을 그대로 둔다 — 실제 배포본(dashboard.html 등)에서는 `@font-face`로 직접 호스팅해 확실히 적용할 것.
- 최소 폰트 크기 **11px** — 게이지 눈금·표 헤더 등 아무리 보조적인 라벨이라도 이보다 작게 만들지 않는다(작게 시작했다가 가독성 문제로 한 차례 전부 올린 이력 있음). 실제로 반복해서 읽는 핵심 데이터(거래 내역 등)는 13px 이상.

### 레이아웃

- 각 정보 단위는 사각 모듈(패널)로 분리, 모듈 사이는 1px 헤어라인. `border-radius: 0`.
- 핵심 수치(예: GDC 잔액)는 오실로스코프 판독창처럼 큰 모노스페이스 숫자 + 임계값(예: 저잔고 경보선)을 바 게이지로 같이 보여준다.
- 탭은 소프트 필(pill)이 아니라 눌리는 물리 버튼처럼: 사각형, 경계선으로 분리, 활성 상태는 배경을 accent 색으로 채움(텍스트 색은 그 위에서 충분한 대비 확보).
- 거래/로그 목록은 컬럼이 고정된 계측 테이블(DATE·TIME·DESCRIPTION·AMOUNT처럼)로, 금액은 우측 정렬 + 부호(+/−) + 색(초록/황)으로 방향을 이중 표시.
- 아직 가동되지 않은 계통(설계 단계 기능)은 별도 색을 새로 만들지 않고, 기존 "주의(황)" 상태색을 재사용한 배너로 표시한다 — 새 의미를 가진 색을 늘리지 않는 것 자체가 원칙.

## 접근성 하한선 (craft 기준 그대로 적용)

- 텍스트 대비 4.5:1 이상(24px+는 3:1) — 다크/라이트 두 팔레트 모두 이 기준으로 골랐다.
- 색만으로 상태를 구분하지 않는다(모양·위치·기호를 함께 쓴다).
- 실제 `<button>`/`<a href>` 사용 — div에 onclick만 붙이지 않는다.

## 다음에 적용할 때 참고

이 원칙은 GDC 탭에서 먼저 검증됐다. 다른 탭(재무제표·세무·대화상대 관리 등)에 확장할 때는:
1. 위 색·타이포 토큰을 그대로 재사용 — 탭마다 새 팔레트를 만들지 않는다.
2. 그 탭에 고유한 "핵심 수치"가 뭔지 먼저 정하고, 그것만 오실로스코프 판독창 취급을 받는다(모든 숫자를 다 크게 키우면 위계가 사라진다).
3. 아직 안 되는 기능은 "설계 단계" 배너로, 절대 실제 동작하는 것처럼 보이게 꾸미지 않는다.
